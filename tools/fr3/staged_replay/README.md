# P0 重播独立候选包

## 2026-09-08：修复夹爪重复发现

SDK 可能同时报告同一夹爪的 msg_type=2 和 msg_type=3。现在仅在设备编号、IP、端口、序列号、类型、固件、能力和协议版本全部一致时合并消息，不再按消息条数误判为多台设备；若同一编号出现不同地址或稳定信息冲突，仍拒绝连接。原始消息和去重结果均保留在准备报告中。地址提示更新为只读核实过的 `192.168.1.119`，DHCP 地址变化时仍按指定设备编号发现，不选择手持 BOX。

此修复不改轨迹、速度、原生控制器、夹爪反馈看门狗或碰撞保护，也不启动真机；运动期间的夹爪反馈超时仍是独立的待验证问题。

## 2026-09-08：一次启动入口

在新包目录执行 `bash run_replay_once.sh 0`，调用本身就是启动授权，不再逐段输入 `RUN …`。仅运行所选 Episode 一次，按顺序完成小幅起步测试、到达首帧、完整重播；不会循环，不会在故障后跳段、复位或重试。几何准备与状态复查仍会花时间，各阶段仍有停止/切换，不是取消检查或把首帧过渡与数据段拼成一条无停顿轨迹。底层等价于 `bash run_replay.sh 0 full-replay --execute`。

新入口禁止自动切换夹爪模式。夹爪必须已处于控制模式且宽度稳定；如果设备掉电或回到采集模式，直接报错退出，不再以 `set_mode(1)` 尝试使能。此前这个操作确实造成了夹爪自行合拢；禁止切换是在主机侧避免触发该行为，不代表固件已经修复。

所有文件哈希、计划绑定、上一阶段成功、起点一致性、碰撞/桌面检查、关节与 TCP 跟踪、通信及夹爪反馈看门狗仍保留。界面确认取消不代表扩大运动权限或已完成硬件验证。本版只做软件测试和部署，不启动真机。

部署前发现的实际测试记录：旧包的 5 秒起步测试成功；随后到首帧运行约 7.445 秒时因 `Gripper measurement watchdog expired` 停止，尚未完成整段真机重播。新版本没有放宽或移除这个保护，也没有宣称解决该反馈问题。

## 交互式入口与检查说明

本包是独立的低速真机测试候选版本，尚未完成实体停止距离认证。旧入口和生产 panda-py 环境不修改。没有自动发出的运动授权：由现场操作者逐阶段核对摘要并确认具体路径。

在 Thor 的本目录执行 `bash run_replay.sh 0 full-replay`，仍可使用旧式逐阶段确认界面。Episode 1 将参数 0 改为 1。每阶段先读取当前状态并进行几何检查；取消或失败立即终止，不重试、不跳到下一段。交互模式需要终端，不使用 sudo；此新包所有入口均禁止自动切换夹爪模式。

单独运行可用 `bash run_replay.sh 0 start-check`、`bash run_replay.sh 0 start-only`、`bash run_replay.sh 0 replay`。后两者要求本版本、同一 Episode 的上一阶段成功日志，且不超过两小时。整段使用原来的低速时间参数，不再使用旧的预解算关节重播入口。

`run.sh offline --output <新的结果目录>` 仅核对文件、模型、轨迹和候选扩展，不连接设备。

`run.sh read-only --output <新的结果目录>` 读取机械臂状态、TCP/负载配置以及指定夹爪的新鲜反馈。夹爪连接只做发现、模式查询、数据接收，不切模式，不开合。机械臂 UserStopped/Reflex 不会被程序解除。

`run.sh prepare --episode 0 --phase start-only --output <新的结果目录>` 只读当前关节和实际夹爪宽度，生成到 Episode 0 首帧的静止起止五次曲线，并检查这条曲线的桌面及自身碰撞。实际宽度在路径中连续变化，不再只检查闭合/半开/全开三个假设。`--phase replay` 检查完整原有时间参数轨迹。两种 prepare 都不移动设备。

执行入口必须同时通过文件哈希、实测起点、Idle 状态、工具配置、新鲜夹爪反馈、几何检查以及绑定这条路径哈希的操作者确认。没有忽略碰撞、跳过故障或自动复位的参数。2026-09-08 用户确认两侧夹爪销轴连接正常后，只对完全落在该局部轴线圆柱区域的网格接触作结构接触分类；不删除整对连杆。半径 6.7 mm、轴向 ±10.1 mm 来自既有模型接触审核加小量数值余量，不是实测销轴尺寸。限定相同 URDF 和网格哈希，轴线不闭合、区外接触、空/非有限/截断接触结果均拒绝。其他碰撞检查保留，既有刚性件/直接父子排除对在报告中列明。现场监控和急停不能代替这些检查。

到达首帧和整段重播各自单独确认；`full-replay` 只负责按序启动阶段入口，不代替确认。正常完成要求机械臂与夹爪均到达末帧；夹爪 SDK 返回成功只表示命令提交，不当作已到位。异常只停止，不自动打开/复位夹爪，不恢复机械臂。突然中断依赖控制器与机器人的停止行为，本包没有经过实测停止距离认证。大角度起步过渡也要保持周围无人和无物，不要只关注夹爪。

真机执行时记录：`arm_telemetry.npz`（原生回调每约 5 ms 一条、预分配缓冲）、`transport_events.json`（夹爪新反馈及命令提交）、`execution_result.json`（完成/故障）、`report.json`。arm 数据列依次为：控制时间 1 列、q 7 列、dq 7 列、O_T_EE 列主序 16 列、目标 q/宽度 8 列、测量宽度 1 列、通信成功率 1 列、估计外部关节力矩 7 列，共 48 列。状态数据来自原生回调，Python 监督循环不读取 Panda 日志锁或写磁盘；退出后才保存完整日志。进程被强制杀死/掉电可能丢失尚未写盘的记录。

桌面模型：base X ≥ 0.1336 m、Z ≤ 0.110 m，Y 无限延伸；另检查向机械臂扩大 5 mm、向上扩大 5 mm 的敏感性情形。尚不包括负载物、线缆、另一台机械臂和未指定障碍物。离散碰撞检查不等同连续碰撞证明，10 mm 诊断距离不等同停止距离。
