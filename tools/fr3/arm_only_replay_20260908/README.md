# P0 只动机械臂测试入口

新独立目录 `/home/nvidia/box_api/replay_p0_arm_only_20260908`，旧入口未修改。
采用现用最新 P0 / BOX 2.0 解算的两条慢速关节轨迹，保留全部关节系数和时间。
Episode 0 重播部分约 181.1 秒，Episode 1 约 131.4 秒；另有起步检查和到首帧的时间。

仅新增独立 `ArmOnlyReplay` 控制器，不调用 BOX SDK，不发现、控制或读取夹爪，
没有伪造夹爪新鲜反馈；日志中的夹爪实测宽度为 NaN（未测量）。
原来的带夹爪控制器及其新鲜度保护原样保留。
机械臂限位、虚拟墙、速度/加速度/jerk 限制、控制回调时序、关节/TCP 跟踪、
工具配置校验、故障停止仍保留。不恢复错误、不重试、不改 RT/NIC 设置。
终点误差条件由 0.01 收紧至 0.0015 rad，便于满足下一阶段 0.002 rad 起点校验。

## 真机命令（用户在 Thor 终端执行）

```bash
bash /home/nvidia/box_api/replay_p0_arm_only_20260908/run_arm_only.sh 0 --execute
```

Episode 1 将 `0` 改为 `1`。不要同时运行多个入口。
程序先要求输入**当前两指尖实际净距离，单位 mm**，以及现场确认 `YES`。
确认的前提：夹爪空夹且会保持开口不变、人员和障碍物离开运动范围、急停可用。
不知道宽度、夹爪会自行合拢或夹有物体时，取消，不填估计的默认值。
断网不等于断电或机械锁定；程序不替用户改变夹爪状态。

先按申报开口检查全臂、夹爪、已测空桌面的几何，再执行
5 秒小幅起步 → 到首帧 → 全段机械臂轨迹。任一检查/阶段失败即结束。
检查是离散几何诊断，不是连续碰撞/制动距离或实体安全认证。
当前状态改变超过允许范围会拒绝使用准备好的起步轨迹。

夹爪固定后，实际接触中心不再按采集开合变化，**不能称为完整抓取重播**，
也不能据此验证夹爪通信或动态接触 TCP 的真机跟踪精度。
本版本只适合空载机械臂动作测试。

## 验证与日志

9 项离线回归测试通过：两条整段理想跟踪、关节系数/时间不变、无夹爪 API/SDK、
变化开口拒绝、回调超时、外部停止、跟踪误差、TCP 不一致、速度包络错误触发停止。
没有运行真机动作；启动时仍须通过现场状态及碰撞检查。
日志在该独立目录的 `logs/`，包含输入计划、几何结果、机器人快照及机械臂遥测。
