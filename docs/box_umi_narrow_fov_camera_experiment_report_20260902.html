窄 FOV 相机更换实验报告

结论：不建议为了降低当前轨迹误差而更换窄 FOV 相机。它直接改善的是角点随机精度，而当前误差主瓶颈是外参 accuracy；但若目标改成“让更小 marker 稳定可检、缩小 marker rig”，窄 FOV 是值得单独评估的机械封装变量。

日期：2026-09-02 主参考：trajectory GT roadmap v17.3-v17.6 判定：不作为轨迹修复项更换 潜在价值：小 marker / 小 rig 优先级：把环境固定 marker 做成常驻监视器

本报告从 BOX 高精度 UMI Trajectory GT & Dual-FR3 Replay Roadmap 单独抽取窄 FOV 相关证据；完整误差预算背景见 3 mm 误差预算证据册 与 roadmap 版本历史。

一页结论

轨迹误差修复项不更换
决策句：作为当前轨迹误差修复项，窄 FOV 镜头的直接正收益封顶在角点 precision，量级只有 0.027-0.116 mm；当前相机侧误差约 2 mm，且主要是外参 accuracy 偏置。七台全换会让 cam_09 丢掉全部 9 个环境固定 marker 观测，正好破坏当前最有价值的相机被碰检测通道。这里的 9 个是环境固定 marker，不是 marker rig；cam_09 对 marker rig 的可见数另算，最多约 3 个。但这不否定另一个价值：在 marker 仍落在视场内时，窄 FOV 可以提高同尺寸 marker 的像素占比，从而支持更小 marker / 更紧凑 marker rig；这是 detectability 与 mechanical packaging 收益，不是 trajectory accuracy 收益。

这不是“窄 FOV 没有任何物理好处”。它确实可能提高每个角点的角分辨率，尤其在大偏角处；也可能让原本低于检测阈值的 marker 变得可识别，或者允许使用更小的物理 marker。但本系统的轨迹误差超支不是角点白噪声主导，而是外参偏置、相机被碰、跨采集世界变化、以及生产 cube 口径下的 marker→TCP 未标定和夹爪刚性问题。更精确地读一套已经偏了的外参，只会得到更精确的错误答案。

换窄 FOV 能不能把当前轨迹误差压到 3 mm 目标附近？ 看它是否作用在 p95 误差主项上，而不是只改善角点随机项。 不能。rig 口径当前 TCP 平移 p95 约 5.5-7.4 mm；A′ 估计仍约 3.8-4.0 mm。角点通道的最大可省量不足以翻转结论。
单台窄 FOV 相机是否提供可观角点 precision 收益？ 用实测相机模型和当前角点通道误差量级换算到 TCP 贡献。 有，但太小。81.6° 镜头在实际工作偏角下把角点通道从 0.116 mm 压到 0.089 mm，仅省 0.027 mm。
七台全部更换是否避开“混 FOV 格式不可表示”的工程问题？ 不混镜头，按同位置同朝向模拟所有现役相机的窄视锥。 避开了格式问题，但引入更大的测量链损失。环境固定 marker 观测从 36 个降到 22 个，cam_09 变成 0/9。这个 0/9 不计 marker rig；cam_09 的 marker rig 可见数另算，最多约 3 个。

方法

不动硬件 + 既有采集

roadmap 中涉及两类窄 FOV 判定：第一类是一台 81.6° 镜头装在 cam_01 上的单台实验，用于估计角分辨率与角点通道收益；第二类是 2026-09-02 追加的“七台全换”模拟，用同位置同朝向的 81.6°×52.0°直线视锥套在现役相机上，检查 marker rig 与环境固定 marker 是否仍落在视锥内。

  • 单台实验输入：2026-09-01 当天 ep0 单路数据；拟合出的真实参数为 HFOV 81.6° / VFOV 52.0° / DFOV 89.7°，f=1091 px/rad，held-out 0.202 px，覆盖 88%。
  • 全换模拟输入：20260901_182755/ep0 的 123 帧；用等距鱼眼像素转换为视线角，再判断是否落入窄视锥。
  • 配套 accuracy 证据：同一份录制、同一批检测缓存、同一份 layout、同一组 marker ID 过滤，只换 fixed_camera_run_name，比较 calib_20260820_173825 与 calib_20260902_103833。
  • 小 marker 推算口径：只把角分辨率增益当作一阶比例尺，不声称已验证检测稳定性。若实际偏角附近增益约 1.2×，则保持相近像素尺寸时 marker 线性尺寸约可按 1 / 1.2 缩放。

小 Marker 与机械封装价值

单独评估，不并入轨迹精度结论
新增结论：窄 FOV 不值得为了降低当前轨迹误差而换，但如果目标是“让更小 marker 仍可稳定检测、缩小 marker rig”，它是值得单独评估的。这条收益属于 mechanical packaging / detectability，不属于 trajectory accuracy。

在相机位置不变、marker 仍落在视场内时，窄 FOV 会让同尺寸 marker 占更多像素，因此确实可能把原来低于检测阈值的 marker 拉到可识别范围；反过来，也允许使用更小的物理 marker。roadmap 中的 cam_01 数据支持“marker 像素会变大”这个方向，但那次距离与镜头效应混在一起，不能直接把 1.46-1.94× 当作纯 FOV 收益。

推算项数值含义
实测镜头 HFOV 81.6° / VFOV 52.0°，f=1091 px/rad 规格“80°”按水平口径读；和现役等距鱼眼 1002 px/rad 的基础焦距差不大。
角分辨率增益 10° / 20° / 30° / 40° 偏角约 1.14× / 1.30× / 1.60× / 2.11× 实际 marker 中位偏角 16.3°，所以可粗读为约 1.2×，不是 129/80 那种大比例。
marker 尺寸一阶折算 48 mm / 1.2 ≈ 40 mm 有机会把当前 marker rig 允许下限 48 mm 粗降到约 40 mm，仍保持相近像素尺寸；不是缩小一半。
潜在间接收益 更小 marker → 更紧凑 rig → 可能减小 marker→TCP 杠杆臂 这条可能比直接提高角点精度更值得关注，但必须和新 rig 结构、遮挡、视场余量一起评估。

有效证据

用于决策
证据roadmap 读数对窄 FOV 决策的含义
E1 · 当前超支项在外参 accuracy 8 相机内外参 / 三角测量目前实际误差约 2.0 mm，超预算 2.5×；超出的 1.2 mm 全部在外参，且几乎全是旋转。cam_09 解出 1.988° 旋转错，端到端 p50 3.66 → 3.42 mm。 换镜头不直接修复外参偏置。当前首要问题是发现并纠正“世界变了”，不是再提高角点读数。
E2 · bootstrap 证明采样噪声不是主项 200 次标定 bootstrap 的有限样本散布只有 0.0068° / 0.060 mm，折算标签位移 p50 0.156 mm，约占 2.0 mm 相机行的 1%。 更准的图像测量只作用在很小的随机项上，无法吃掉 2 mm 级系统偏置。
E3 · 角点通道收益封顶很低 角点通道整条只值 0.116 mm；单台 81.6° 镜头按实测工作偏角代入后，从 0.116 mm 降到 0.089 mm，净省 0.027 mm，约为 p50 缺口的 1%。 即使窄 FOV 赢了角点 precision，收益也无法改变“轨迹误差是否达标”的结论。
E4 · 全换会损失相机被碰监测 现场 9 个环境固定 marker 在跨采集无人触碰时中心变化中位 0.07-0.48 px = 0.004°-0.028°；对 cam_09 的 1.988° 被碰事件信噪比 72×-483×。套窄视锥后，36 个环境固定 marker 观测只剩 22 个（61%），cam_09 为 0/9。这不是 marker rig 计数；cam_09 在 marker rig 上最多约 3 个 marker。 窄 FOV 会削掉当前最便宜、最直接的 accuracy 监视器。它不是收益≈0，而是负收益。
E5 · 垂直视场没有余量 在一条居中的 30 秒轨迹上，窄 FOV 垂直半视场 26.0° 的剩余量已经很紧：cam_13 -0.3°、cam_12 +1.5°、cam_09 +2.4°、cam_14 +4.3°；cam_07 已经装不下。 当前模拟只是作业体积下界。真实作业更大时，窄 FOV 的覆盖风险只会增加。
E6 · 缩短标定间隔也不是主杠杆 把标定从录制前 12 天换成录制后 16 小时，逐相机弥散中位只降 0.25 mm（7.2%），标签位移中位 0.766 mm。结论改为：杠杆是检测相机被碰，缩短间隔只值不到 10%。 accuracy 的主问题不是“多采一点、换新一点、像素准一点”能解决，而是要有持续监控和生产闸门。

已撤销或降级的证据

不再作为依据

v17.4 对 v17.3 做了关键纠偏：一次临时分析把场景固定 marker 混进 rig marker 统计，导致若干“直觉为什么不成立”的解释失效。报告保留这段，是为了避免后续继续引用已作废的数字。

原说法状态正确读法
cam_01 的 marker 成像 97.5-122.2 px，现役 34.8-66.9 px，因此窄 FOV 成像优势 2.3-2.9×。 下修 现役 marker 成像应为 52.2-81.1 px；cam_01 优势改为 1.46-1.94×。距离与 FOV 共线仍成立，但量级没有初稿夸张。
cam_01 每帧贡献约 8 个角点，而 cam_09/13/14 各 40-44 个角点。 撤销 40-44 个角点混入了固定 marker。按 rig 五 ID 重算后，cam_01 为 6.5-9.9，最好的现役为 9.7-11.4。
两次 rig 采集无法评估窄 FOV，因为 cam_01 的 ≥4 marker 帧不足。 撤销 真实门槛是 ≥4 个角点，即 ≥1 个 marker；cam_01 有 113 / 123 帧合格。真正阻碍是 cam_01 当时没有外参，不能进 BA。
窄 FOV 会看不到 rig。 撤回 七台全换模拟显示 rig 观测保留 87%-100%。真正负面项不是 rig 立即丢失，而是环境固定 marker 监测被削弱、垂直 FOV 余量不足。
未被撤销的主依据：角点通道收益上限 0.116 mm、窄 FOV 单台净省 0.027 mm、相机行 2 mm 中只有约 1% 是采样噪声、七台全换削弱环境固定 marker 监测。这些证据不依赖被撤销的混 marker 统计。

决策矩阵

净收益为负
维度窄 FOV 影响
角点 precision小幅改善，已量化为 0.027 mm 级收益。
marker detectability可能改善。在视场仍覆盖 marker 时，同尺寸 marker 占更多像素；也可能把当前 marker rig 允许下限 48 mm 粗降到约 40 mm。
机械封装 / marker rig 尺寸可能间接有利。更小 marker 可能让 rig 更紧凑，并进一步减小 marker→TCP 杠杆臂；该收益需要随新 rig 机械方案单独评估。
外参 accuracy不修复。当前 2 mm 主项仍在。

工程成本全换需重做场景基准；混 FOV 在现行生产格式中不可表示。
综合判定不作为当前轨迹误差修复项执行。除非同时重做场景基准，否则全换为负收益；即使重做，仍不解决当前 accuracy 主瓶颈。但作为小 marker / 小 rig 的设计变量，保留单独评估价值。

建议动作

替代主线
  • 不要采购 / 更换窄 FOV 镜头作为当前轨迹误差修复项。
  • 允许把窄 FOV 放进新 marker rig 的机械封装评估：目标不是压低现有轨迹误差，而是验证更小 marker 是否仍稳定可检、rig 是否能更紧凑、marker→TCP 杠杆臂是否能随之减小。
  • 小 marker 评估要设独立判据：在目标作业体积内逐相机统计 marker 像素边长、检测率、误检率、姿态解稳定性、遮挡余量；不要用重投影残差替代 detectability。
  • 把环境固定 marker 做成常驻相机健康监视器：检测本来就在跑，存基线并按 3σ 比较；这是 v17.6 直接派生出的 P0。
  • 补齐环境固定 marker 盲区：cam_12 与 cam_01 当前各 0 个，需补贴 2-3 个。
  • 继续把主线放在 accuracy：相机被碰检测、生产标定指针陈旧闸门、外参提升流程、以及生产 cube 口径的 marker→TCP / hand-eye 和装夹刚性。

边界条件

不能过度外推
  • 干净的“同位置同朝向、只差镜头”的并排 A/B 从未做过；roadmap 主动放弃该实验，因为即使它赢，收益封顶 0.027-0.116 mm，对决策无影响。
  • 当前所有误差数仍未由独立 GT 最终认证。它们足以证伪“窄 FOV 是主杠杆”，但不能替代 Phase 7 的独立 GT benchmark。
  • 如果未来目标变成更换 marker rig、使用更小 marker、改变作业体积、或重做整套场景基准，窄 FOV 应作为新系统设计变量重新评估；这不是当前修复 3 mm 轨迹误差的动作。
