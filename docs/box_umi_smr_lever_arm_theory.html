用激光跟踪仪认证 TCP 位置 3 mm

目标是生产标签里 TCP 位置的误差不超过 3 mm。本文从测量模型讲起：怎么从静止片段求出 SMR 杠杆臂，为什么球心上的残差不能直接当成 TCP 的误差，以及怎样用一次跟踪仪 pivot 在 TCP 处直接测出最大的那一项。整条路径都不需要测旋转。

v2 · 2026-09-22只讲原理，不含实验数据
相机侧测量 跟踪仪侧测量 待求未知量
摘要
  1. TCP 位置由 cube 位姿和一个 3 维常量 cTCP（TCP 在 cube 系里的坐标）算出，TCP 的姿态不参与。所以“只认位置”时，要认证的是 cTCP 和相机位姿序列，不需要任何旋转真值。
  2. TCP 位置误差分三部分：常量（cTCP 本身错了）、静态随姿态变化的部分、运动带来的动态增量。三部分由不同的实验测。
  3. SMR 常驻夹爪钢片，跟踪仪只测得到它的球心。先用 15–20 个静止片段解出跟踪仪站位 TWG 和 SMR 在 cube 系中的位置 c，共 9 个未知量。静止让时间从问题里消失。
  4. 解不解得出看转角，不看方程数：必须绕两根不平行的轴转。解法是交替最小二乘，两步都有闭式解；站位冻结后只解 c，线性、不需要转角，精度约好 4 倍。
  5. c 是拟合量，会吸收所有“在 cube 系里恒定”的相机误差。因此球心上的残差说明不了 cTCP 对不对，也就是说明不了 TCP 位置的常量部分。
  6. 补上这一项的办法是跟踪仪 pivot：TCP 卡在球窝里转，钢片上的球心画出一个以球窝为中心的球面，跟踪仪单独定出球窝中心，再和生产标签逐位姿比较。cTCP 不拟合、原样代入，常量和静态姿态相关误差都直接在 TCP 处测到。
  7. 动态部分从动态轨迹场的球心残差里拿，再加一个“运动时姿态误差 × 球心到 TCP 距离”的转移项。三窝 AX=XB 和 STS 只在认证 TCP 姿态时才需要，不在 3 mm 位置目标的路径上。

1目标：TCP 位置 3 mm，只需要平移

目标是生产标签里 TCP 位置的误差不超过 3 mm（按 GT 链预算的 p95 口径），GT 链自身的误差要压在 1 mm 以内，才有资格裁决 3 mm。

生产管线这样算 TCP 位置：

pTCP,i = Ri cTCP + ticube 位姿接上 TCP 在 cube 系里的坐标
(1)

cTCP 是 3 个数，来自 marker → TCP 标定。TCP 的姿态不出现在式 (1) 里，所以标定结果里的旋转，只通过它对 cTCP 的影响起作用。例如“标定旋转偏 2°、乘两百多毫米力臂、约 9 mm”那一项，在位置口径下就是 cTCP 的一个误差来源。于是只认位置时，要认证的只有两样：cTCP 和相机位姿序列 (Ri, ti)。两样都不需要旋转的真值。

但相机的旋转误差并没有因此变得无关：旋转错 δθ，TCP 就偏 δθ × cTCP。它是一个位置误差，只是经力臂放大后进来的。所以 TCP 位置误差按来源分成三部分：

部分典型来源由哪个实验测
常量
每个位姿都一样（cube 系里）		cTCP 本身错了：pivot 平移误差、从另一侧拷贝、标定旋转 × 力臂跟踪仪 pivot，§9
静态、随姿态
静止时就有		相机平移误差；相机旋转误差 × |cTCP|；可见相机组合变化跟踪仪 pivot，与常量部分一起直接测，§9
动态增量
只在运动时出现		时钟偏差 |v|·Δt、运动模糊、平滑器动态轨迹场（球心）+ 转移项，§10

三个实验共用一样东西：跟踪仪站位 TWG。它和钢片上 SMR 的杠杆臂 c，都从 15–20 个静止片段里解出来，这就是 §2–§8 的内容。§9–§11 再讲怎么从球心走到 TCP，以及 3 mm 怎么拼出来。

2两台仪器，一个点

跟踪仪给的是一个点。SMR 是装在钢球里的角锥棱镜，激光打进去沿原路返回，跟踪仪由此以 1 kHz 测出球心的三维坐标 p，表达在跟踪仪自己的坐标系 G 中。不论球怎么转，回光都一样，所以跟踪仪对姿态完全看不见。

相机给的是一个位姿。多路相机看 cube 上的 AprilTag，解出 cube 坐标系 B 在相机 world 系 W 中的位姿 (R, t)，6 个自由度，约 60 fps。

SMR 经磁吸窝固定在夹爪本体的钢片上，与 cube 构成刚体。于是在 cube 系里，球心的位置是一个常量，记作 c。这就是要求的“SMR 到 cube 中心的变换”。严格地说它只有平移：给一个点定义姿态没有意义，非要写成 4×4 矩阵，就是旋转取单位阵、平移取 c，旋转部分怎么取都不影响任何结果。

同一个球心，两种说法

在第 i 个静止位姿上，两台仪器各自说出球心在 world 系中的位置：

Ri c + ti相机说：cube 位姿把 c 搬进 W RWG pi + tWG跟踪仪说：站位把 p 搬进 W
(2)

两者说的是同一个球心，所以对每个位姿都应相等：

RWG pi + tWG = Ri c + tii = 1, …, N
(3)

黑色的是未知量：c 3 个，站位 TWG = (RWG, tWG) 6 个，共 9 个。我们本来只关心 c，但站位绕不开：两台仪器各说各的坐标系，不先把它们对上，c 就无从谈起。式 (3) 是求杠杆臂的出发点。

3为什么要静止

静止让时间从问题里消失

式 (3) 里没有时间。运动时情况不同：跟踪仪用控制器的钟打时间戳，相机用 Thor 的 CLOCK_MONOTONIC，两者差 Δt 就会在残差里留下 |v|·Δt，1 m/s 下差 5 ms 就是 5 mm。静止时 v = 0，这一项恒为零，时钟对齐的问题整个从注册里拿掉了。驻点集只需要知道“哪些相机帧和哪些跟踪仪样本属于同一个驻点”，精度到段级就够。

一个驻点，平均成一行

2 秒的驻点里，跟踪仪约有 2000 个样本，相机约 120 帧。各自平均成一个数：

  • pi：跟踪仪样本的算术平均。随机误差按 σ/√N 下降，2000 个样本约缩小 45 倍，只剩微米量级。
  • ti：相机平移的算术平均。
  • Ri：相机旋转的弦平均。先把旋转矩阵逐元素相加取平均，再用 SVD 投影回最近的旋转矩阵（M = UΣV⊤ → UV⊤，行列式为负时翻转最后一列）。直接平均出来的矩阵不是旋转。驻点内姿态几乎不变，弦平均和测地平均的差别可以忽略。

平均只能消掉抖动，消不掉偏差。相机若在某个姿态下系统性地偏 1 mm，平均 120 帧后还是偏 1 mm。这正是后面要测的东西。

由谁判断“静止了”

用跟踪仪判，不用相机。跟踪仪 1 kHz、微米级，它判断“动没动”不依赖注册、不依赖时钟链，也不依赖被检验的相机管线，判据不落在被判的东西身上。三个细节：

  1. 速度按 50 ms 窗口算，不按相邻样本差分。1 kHz 下相邻差分等于把几微米的噪声除以 1 ms，得到每秒几毫米，静止的球永远像在动。改成“窗口内位移 ÷ 窗口时长”，阈值 2 mm/s 才有它字面上的意思。
  2. 两端各剪掉 0.3 s。刚停下时的回稳和准备离开时的起步都慢到能过阈值，但都不是这个位姿。剪完后至少剩 2.0 s 才算一个驻点，所以每段实际要静止 ≥ 2.6 s。操作上建议停 3.5–4 s。
  3. 晃动和漂移分开对待。span 是驻点内各样本到均值距离的极差，代表来回晃，属于振荡，能被平均掉，门槛放宽到 0.30 mm。drift 是后三分之一均值相对前三分之一均值的净位移，属于偏置，平均不掉，门槛更紧，为 0.15 mm。同时要求驻点里至少有 30 帧相机数据。

15 段是一个集合，不是 15 个

一段录一个位姿，段的边界就是驻点的边界。15 段来自同一次安装（同一个 mount_id），共享同一个 c，所以它们合成一个集合进入拟合。这不是记账细节：下一节的可观测性靠同一集合内的位姿两两相减，如果把 15 段当成 15 个单位姿集合，就一对也凑不出来，转角再大也会被判成“没有转动”。

4什么时候解得出

按方程计数，15 个位姿 × 3 = 45 个方程，9 个未知量，看起来绰绰有余。但方程数从来不是问题所在。把式 (3) 对两个位姿相减，tWG 被消掉：

(Ri − Rj) c = RWG (pi − pj) − (ti − tj)
(4)

左边是关于 c 的全部信息，而它被 Ri − Rj 乘着。

直觉 · 纯平移为什么没用

假设 15 个位姿姿态完全相同，都是 R。把 c 换成 c + δ，同时把 tWG 换成 tWG + Rδ，式 (3) 两边同时多出 Rδ，每个方程照样成立。c 和 tWG 其实是同一个未知量的两个名字，数据分不开它们。

只绕一根轴也不够。绕单位轴 n 转角 θ 时，R − I 的三个奇异值是 2 sin(θ/2)、2 sin(θ/2)、0，零对应的方向正是 n。几何上看，cube 绕 n 转，球心在垂直于 n 的平面里画圆弧，沿 n 的分量纹丝不动，所以 c 沿转轴的那一分量看不见。结论：必须绕至少两根不平行的轴转动。这和手眼标定 AX = XB 要求的条件同源。

把“转得够不够”变成一个数

把同一集合内所有位姿对的 Ri − Rj 竖着堆起来，按位姿对数归一化后取最小奇异值，记为最弱增益 gmin。它表示在最难观测的方向上，一对位姿平均能提供多少关于 c 的信息，可以直接和单轴的 2 sin(θ/2) 比较。量级上：

σc ≈ σpose ⁄ (gmin √N)联合求解站位与 c 时
(5)

两条直接推论：

  • 转角比位姿数值钱。gmin 是一次方，N 在根号里。把第二根轴转开，远比多采几个位姿有用。
  • 转得少的那根轴说了算。把一根轴转到 90° 而另一根只转 5°，gmin 仍由 5° 那根决定。下面的计算器里可以直接看到。

联合解的门槛是 gmin ≥ 0.05，约等于单轴转 2.9°。这是“能不能解”的地板，不是质量目标；达不到时拟合直接拒绝，并在报错里说明该往哪根轴转。

联合解一栏按式 (5) 粗估，偏乐观：联合解还要同时估站位的旋转，仿真中实际误差比这一栏再大约 1.4 倍。冻结站位一栏的公式见第 6 节。

站位还需要点在空间里张开

求 RWG 需要 15 个球心在空间里散开。它们如果共线，绕这条线的旋转就没有约束。实现里要求点云的 planarity（中心化点云最小与最大奇异值之比）≥ 0.10，直径 ≥ 0.30 m。严格说只有共线才真正退化，共面的点本身能定旋转，所以这条门槛偏保守。保留它是因为多做一点高低差几乎不花成本。

SMR 的接受角正好给了两根轴

角锥棱镜对偏离光束的倾斜只接受约 ±30°，超出就断光。绕光束方向的滚转则不受限，因为棱镜绕自身光轴转动时回光不变。所以可用的转动恰好是“滚转 + 有限倾斜”两根不平行的轴。滚转过头时，重力会把球从磁吸窝里拽出来。

5怎么解：交替最小二乘

把式 (3) 两边之差的平方和作为代价：

J(RWG, tWG, c) = ∑i ‖ RWG pi + tWG − Ri c − ti ‖2
(6)

9 个未知量混在一起时，这是带旋转约束的非线性问题。但把未知量分成两块，每一块单独看都有闭式解。

第一块：固定 c，求站位（Kabsch）

c 已知时，qi = Ric + ti 就是相机预测的球心。于是 pi 与 qi 是 15 对对应点，求站位就是经典的刚体点集配准：

H = ∑i (pi − p̄)(qi − q̄)⊤ = U Σ V⊤ RWG = V diag(1, 1, d) U⊤,d = sign det(VU⊤) tWG = q̄ − RWG p̄
(7)

先对齐质心，再用 SVD 求最佳旋转。d 用来防止解出镜像。这一步对给定的 c 是全局最优。

第二块：固定站位，求 c（一次平均）

站位已知时，记 yi = RWGpi + tWG − ti，代价变成 ∑ ‖Ric − yi‖2，对 c 是线性的。因为 Ri⊤Ri = I，正规方程的系数矩阵恰好是 N·I，解就是一个平均：

c = (1/N) ∑i ci,ci = Ri⊤ (RWG pi + tWG − ti)
(8)

这个结果很好解释。ci 是把跟踪仪测到的球心搬回第 i 个位姿的 cube 系里，也就是这一个位姿自己对“球在 cube 上哪儿”的回答。最优的 c 就是 15 个回答的简单平均。这一块的系数矩阵是单位阵的倍数，永远良态，任何病态都来自第一块和两块之间的耦合，也就是第 4 节讲的转角。

交替、单调、收敛

两块轮流做。每一步都是在同一个代价 (6) 上对自己那一块求全局最优，所以 J 只降不升，迭代单调收敛。当一轮之间 c 的变化小于 1 nm，或满 50 轮时停止。

初值不从 c = 0 出发。杠杆臂有十几厘米长时，从零出发可能落进一个浅的次优解。实现里先做一次线性松弛：式 (4) 对 c（3 个）和 RWG 的 9 个元素是线性的，暂时丢掉“RWG 必须是旋转”这一约束，对所有位姿对一次最小二乘解出 12 个数，再把 RWG 投影回最近的旋转矩阵。这个初值已经离答案很近，后面的交替迭代只产生真正的旋转。

只解刚体变换，不解尺度。站位用 SE(3) 而不是 Sim(3)。相机 world 系若有全场尺度误差，正是要暴露的共模误差，让拟合吸收掉就看不见了。尺度另外用 Sim(3) 拟合一次，以 ppm 报告，只作诊断，永不施加。

6第二次起：冻结站位，只解 c

9 个未知量里有两种寿命完全不同的常量：

量是谁的常量什么时候失效
TWG 站位房间的常量跟踪仪挪动，或相机外参重新标定（即 world 系变了）
c 杠杆臂这一次安装的常量钢片或磁吸窝拆装一次，就是一个新的 mount_id

每次都把两者一起从头解，等于每次都扔掉房间的常量，并且每次都要付转角的代价。所以求解拆成两个入口：

  • station 模式（第一次，或累积多场）。联合解：所有场次共用一个站位，每个 mount 各一个 c。只有这一步需要转角。场次越多，站位越准。
  • lever-arm 模式（之后每一场）。站位冻结，只剩式 (8) 那一次平均：线性、每个位姿都直接贡献，完全不需要转角。整场姿态几乎不动的采集在这里也是合法输入。

精度差多少。冻结后 c 就是 N 个独立估计的平均，每个分量

σc = σpose ⁄ √N每轴，与转角无关
(9)

联合解则要再乘上 1/gmin。在 ±30° 的接受锥里，最弱方向的增益大约只有 0.3–0.4，也就是约三倍放大；再加上同时估站位旋转的代价，仿真中两者之比稳定在约 4.4 倍，与噪声大小无关。靠加位姿追回 4.4 倍需要 4.4² ≈ 19 倍的位姿数。所以冻结站位不是运维上的方便，而是 c 能否达到 0.20 mm 预算的分水岭：按 (9)，N = 20 时要求 σpose 不超过约 0.5 mm。这是一个可以直接去测的门限。

白送的诊断。跨场次比较独立解出的站位，ΔTWG 同时监视两件事：跟踪仪有没有被碰过，相机外参有没有漂。

7解出来能信到什么程度

每个位姿的残差是式 (3) 两边之差的长度。利用式 (8)，它还有一个等价写法：

ri = ‖ RWG pi + tWG − Ri c − ti ‖ = ‖ ci − c ‖
(10)

即每个位姿的残差，恰好是它自己的回答 ci 离平均值有多远。

三种不确定度，回答三个不同的问题

  • Bootstrap σc：数据把答案钉得多紧。对位姿有放回地重采样 200 次、每次重解，c 的散布就是它的精密度。它看不见第 8 节那些被结构性吸收的偏差，所以是精密度，不是准确度。
  • 留出残差：模型能不能预测。挑几个位姿不参与拟合，解完再算它们的残差。拟合残差是模型给自己打分，只有留出残差说明预测能力。留出 RMS 明显大于拟合 RMS，说明拟合在迁就噪声。
  • 姿态回归：误差有没有结构。见下文。

门槛要求为什么

“≥ 15”数的是拟合集。15 段全部用于拟合，可以通过认证，但没有留出复核；留出 5 段，拟合集只剩 10，不满足门槛。两者都要，就采 20 段：15 段拟合，5 段留出。

姿态回归：散布的大小没用，形状才有用

看 15 个 ci 散得多开，似乎能判断钢片是否随姿态变形。但按式 (10)，这个散布的 RMS 与残差 RMS 是同一个平方和写了两遍，精确相等，不是第二项检查。

能把“钢片随姿态变形 / 相机误差随姿态变化”与“随机噪声”分开的，是散布有没有结构。做法是把每个位姿的回答对它的姿态做线性回归：

ci ≈ β0 + B φi,φi = log(Ri R̄⊤)相对平均姿态的旋转向量
(11)

看回归解释了多少方差（R2），并与纯噪声下的期望比较：每个分量拟合 3 个斜率，纯噪声约能解释 3/(N−1)，N = 15 时约 0.21。当 R2 超过 max(3 × 0.21, 0.05) 时，提示存在姿态相关的结构。B 的最大奇异值换算成 mm/°，就是球心在 cube 系里随姿态“迁移”的速度。它是告诉你往哪看的指针，不是门槛：确认要靠去量钢片，或者去查某些姿态下 cube 的某个面是否被遮挡。

8c 会吸收什么

这是整套方法最需要说清楚的限制。最小二乘会顺手解释掉一切它能解释的相机误差。c 是拟合出来的，任何在 cube 系里恒定的误差都能被 c 原样吸收，于是在残差里恒为零。这不是测得小，而是结构上被消掉了。逐项看相机侧的几类偏差：

相机侧偏差数学形式结果
world 系常量平移t̂i = ti + δW联合解时吸收 被 tWG 吃掉；站位冻结后，只有相对建站那一场的变化可见
cube 系常量平移t̂i = ti + RiδB吸收 ĉ = c − δB
cube 系常量旋转R̂i = Ri δR吸收 ĉ = δR⊤c，且 |ĉ| = |c|
world 系常量旋转（只作用于姿态）R̂i = δRW Ri可见 误差 (δRW − I)Ric 随姿态变，常量复现不出

第二、三行的推导只有一行。以 cube 系平移为例：拟合要找 ĉ 使 Riĉ + ti + RiδB 等于真实球心 Ric + ti，对所有 i 取 ĉ = c − δB 即可，残差为零。旋转那一行同理。

结论 · 球心残差不能直接当成 TCP 位置误差

被吸收的第二、三行合起来，正好就是 marker → TCP 这个常量；对 TCP 位置而言，它就是 cTCP 的误差。所以用驻点拟合出的 c 算出的球心残差，不论多小，都说明不了 cTCP 对不对。这一项要在 TCP 处直接测，见 §9。实现里产物恒写 certifies_marker_to_tcp: false，就是把这句话写进了数据结构。

同一条性质也有好处。SMR 的光学中心相对钢球球心的偏差，在 cube 系里同样是常量，被 c 一并吸收，对残差没有贡献。所以这里不需要 precision 级的 SMR。

还有一个极端情形：如果整场姿态几乎不变（转角 < 5°），所有旋转误差在这一场里都成了常量，全部被吸收，残差退化为纯位置测量，不带任何姿态信息。这种场次合法，但结论里必须写明。

由此还能推出一条纪律：驻点集和被评测的轨迹必须分开采。若在评测数据本身上拟合 c，评测想找的误差会先被 c 吸收掉一部分。

9在 TCP 处直接测：跟踪仪 pivot

§8 的结论是：球心上的残差看不见 cTCP 的常量误差。要看见它，得在 TCP 那一点上直接比较，而且比较时不能再拟合任何 cube 系里的常量。跟踪仪 pivot 正好满足这两条，并且不用挪 SMR。

直觉 · 为什么不直接比两条 TCP 轨迹

最朴素的想法是：从跟踪仪的球心轨迹 q(t) 推出一条 TCP 轨迹，再和视觉的 TCP 轨迹对齐时间后相减。推 TCP 要用 q(t) + R(t)u，其中 u 是 SMR → TCP 的向量。跟踪仪不给姿态，R(t) 只能借相机的 R̂(t)。于是：

( q + R̂u ) − ( R̂cTCP + t̂ ) = q − [ R̂ (cTCP − u) + t̂ ]

R̂u 在两边各出现一次，抵消了。右边正好是“以 cTCP − u 为杠杆臂”的球心比较。所以这场比较能看见什么，完全取决于 u 从哪来：

  • u 用相机数据标定（例如 cTCP − ĉ）：cTCP 错多少，u 就跟着错多少，在差值里消失，回到 §8 的吸收问题。
  • u 用 CAD 量：u 要表达在相机的 cube 系里，这一步需要 cube 相对夹爪本体的旋转，正是没测过的那 2°；乘上几十毫米就是 2 mm 量级。
  • u 由跟踪仪独立测出：cTCP 的误差才会留在差值里。跟踪仪 pivot 做的就是这件事：TCP 钉在球窝里，不需要姿态，跟踪仪单独就能定出 TCP 在哪。SMR 始终留在钢片上。

做法

把 pivot 球窝固定在桌上，夹爪夹住与相机 pivot 标定相同的插件，插件的球头落进球窝。SMR 留在钢片上不动（同一次安装、同一个 c）。以球窝为支点转动夹爪，每个姿态静止 3.5 s 以上，与驻点集用同一个跟踪仪站位。

原理：球心在一个球面上

夹爪绕球窝中心 s 转，钢片上的球心到 s 的距离不变。于是跟踪仪测到的全部球心都落在以 s 为心、半径为 ρ 的球面上：

‖ pi − sG ‖ = ρ两边平方后对 (s, ρ2 − |s|2) 是线性的
(12)

先对展开后的线性方程做一次最小二乘，再做几步高斯–牛顿细化。sG 完全由跟踪仪读数决定，不经过相机，这正是它能当独立参考的原因。

逐位姿比较，不拟合 cTCP

用驻点集冻结下来的站位，把 s 搬进 world 系，再和生产标签给出的 TCP 逐位姿相减：

eTCP,i = ( Ri cTCP + ti ) − ( RWG sG + tWG + Ri d )
(13)

d 是球窝中心到 TCP 的偏距（cube 系里），与生产标定用的是同一个值。两边都加了同一个 d，它在差值里精确抵消。

关键在于这一步什么 cube 系常量都不拟合：cTCP 生产用什么就代入什么，唯一拟合过的站位来自另一场采集，只吸收 world 系常量。于是 §8 表里被 c 吃掉的两行，在这里都以 Riδ 的形式出现，全部看得见。

  • eTCP,i 的平均值（换回 cube 系）就是 cTCP 的常量误差。
  • 它围绕平均值的散布，就是静态、随姿态变化的 TCP 误差。两者合起来，就是静止状态下 TCP 位置误差的分布，可以直接拿去和 3 mm 比较。
  • 免费的一致性检查：半径 ρ 只来自跟踪仪；把 s 按式 (8) 换算到 cube 系得到 ĉs，|ĉs − ĉ| 应该等于 ρ。对不上，说明站位或某一侧的拟合有问题。

怎么转，球心才定得准

球面拟合有一个弱方向：转角小时，数据只覆盖一小块球冠，球心沿球冠对称轴（平均的“球窝 → SMR”方向）最难定。按单位姿误差 0.02 mm、ρ = 70 mm、15 个姿态估算：

转法弱方向 σ球心误差 p95
只在接受角内前后倾 ±25°≈ 0.16 mm≈ 0.34 mm
再加绕光束方向侧倾 ±45°≈ 0.07 mm≈ 0.14 mm
再加绕光束方向侧倾 ±60°≈ 0.04 mm≈ 0.10 mm

数值为仿真估计，用于定采集方法，不是实测。

侧倾之所以能转大，是因为 pivot 时“球窝 → SMR”大致竖直、光束大致水平，绕光束方向转不改变 SMR 相对光束的朝向（角锥棱镜绕自身光轴转，回光不变）。所以 pivot 要大角度侧倾、前后倾留在接受角内。侧倾过头时，重力会把 SMR 从磁吸窝里拽出来，要有防脱措施。

顺带解决的三件事

  • left 的 pivot 平移（相机测，holdout p95 2.70 mm）第一次有独立核对。
  • right 的平移是从 left 拷贝的，最坏可能错 13 mm，这里直接测。
  • 两侧 URDF 之间 6.15 mm 的矛盾：同一站位下两侧各做一次，取差值即可裁决。
看不见的一项 · TCP 的定义偏距 d

d 在式 (13) 里抵消了，所以跟踪仪看不见它。它决定“TCP 到底在哪”，只能用 CAD、卡尺或三坐标单独量，需要量准到约 0.3 mm。生产 pivot 工具给它的默认不确定度是 5 mm；这一项不收紧，3 mm 就无从谈起。

另一种做法（不推荐）：把 SMR 直接装到 TCP 处。这要换安装，钢片上的 c 随之作废，SMR 也离开了动态场的位置，pivot 和动态场就不再共用同一个 c。

10动态部分与转移项

pivot 只覆盖静止姿态。运动带来的额外误差要从动态轨迹场里拿：SMR 在钢片上，c 用冻结站位拟合，测到的是球心处的误差 eball(t)。把它搬到 TCP：

eTCP(t) ≈ eTCP,static + [ eball(t) − eball,static ] + δθdyn(t) × (cTCP − c)
(14)
  • 第一项：静态 TCP 误差，由 §9 在同一姿态范围内直接测。
  • 第二项：运动造成的增量。在动态场里按速度分档，减去同一姿态区间的静态水平，剩下的就是运动带来的部分，如 |v|·Δt、运动模糊、平滑器的影响。
  • 第三项（转移项）：运动时额外的姿态误差，乘以球心到 TCP 的距离。这段距离由 §9 实测（约为 ρ 加减 |d|，几十毫米）。

转移项有两个来源，处理方式不同：

  1. 时钟偏差造成的姿态滞后 ω·Δt：可以算。角速度 2 rad/s、时间偏差 0.3 ms、距离 70 mm 时约 0.04 mm，可以忽略。
  2. 其余运动引起的姿态误差（运动模糊、跟踪滞后等）：只看一个点测不出来，只能给一个假设的上界，并写进结论。可以作为佐证的是：球心残差里含有 δθdyn × c，而 |c| 比球心到 TCP 的距离大，所以球心动态增量小时，这一项通常更小。但单点上平移误差和旋转误差可能互相抵消，这不是严格上界。

先做固定姿态的动态场次：姿态钉死时 ω ≈ 0，第一种来源为零，第二项就是纯粹的位置链误差。再做真实操作场次，两者相减得到姿态相关的动态误差。

合成。各项默认按线性相加，这是保守做法；只有在能说明各项相互独立时，才改用平方和。

统计量用偏差本身，不用标准差。逐点算出 |e(t)| 后，和 3 mm 比的是它的 p95（或 RMS），不是标准差。标准差先减掉了均值，而均值恰恰包含 cTCP 的常量误差，可能有好几毫米。只报标准差，最大的一项就被悄悄删掉了。

三条纪律，否则数字会偏乐观：

  1. 参考不能在被评测的数据上拟合。站位、杠杆臂、时间偏差都要来自另外的采集（驻点集、pivot、时钟链）。在评测轨迹上拟合的任何量，都会吸收掉一部分真实误差。用两条轨迹做互相关来对齐时间尤其要避免：它会把所有随速度增长的误差一起吸收。
  2. 按速度分档报，不报一个池化数。一条轨迹里大部分帧接近静止，池化后的 p95 会把高速段的误差淹没。每个速度档单独报，峰值速度那一档才是判据。
  3. 写明覆盖率。只有跟踪仪有效的帧才进统计，而断光多发生在遮挡、大角度、快速运动这些最难的工况。结果只对被覆盖的帧成立，是全体误差的下界。

结论的写法。认证结论只对测到的范围成立，前提要写全，例如：

结论模板

在已测的速度档（≤ … mm/s）与姿态范围（相对跟踪仪 …°）内，left / right 两侧 TCP 位置误差 p95 ≤ 3 mm。前提：TCP 定义偏距 d 按 ±0.3 mm；动态姿态误差按 ≤ …° 计；带 SMR 工装的构型。

不在这条路径上的。三窝 AX=XB 与 STS 6D 靶测的是 TCP 的姿态。只认位置时，它们不是必需项；要认证 TCP 姿态时再做。

12从理论推出的采集口径

  • 驻点集采 20 段。15 段拟合、5 段留出；每段静止 3.5–4 s，手离开。§3 §7
  • 驻点集绕两根不平行的轴转开，位置在三维里张开。滚转与倾斜都做；左右、前后、高低都拉开，直径 ≥ 0.3 m。§4
  • 跟踪仪 pivot 两侧各做一场。每场 ≥ 15 个静止姿态；侧倾 ±45–60°，前后倾留在 ±25° 内；插件与相机 pivot 标定相同。§9
  • 量准 d。球窝中心到 TCP 的偏距，CAD、卡尺或三坐标，约 0.3 mm。§9
  • 动态场先固定姿态，再真实操作。按速度分档，峰值速度要覆盖生产速度。§10
  • 全程光束锁定。断光的驻点直接作废，不要补。§3
  • 所有场次同一站位、同一次安装。跟踪仪不挪，钢片与磁吸窝不碰；挪了或拆过，站位或 c 就要重做。§6
  • 驻点集、pivot 与评测轨迹分开采。§8
