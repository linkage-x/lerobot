BOX UMI 分布式夹爪 Marker Rig 供应商设计需求

用途：用于夹爪端 AprilTag / marker 的刚性安装、视觉定位与后续 TCP 标定。

本文为供应商沟通版，供结构设计、报价、打样、装配和质检使用。

文档版本V1.0
日期2026-08-13
阶段原型设计 / DFM 评估
对象BOX UMI 夹爪 marker carrier

1. 项目目标

设计并制造一套低矮、刚性、可重复装配的夹爪端 marker carrier。该 carrier 需要把多个 marker 固定在同一个刚体上，并在夹爪工作过程中保持相对位置稳定。

现有高位 marker cube 在工作空间中存在高度偏大、遮挡风险高、与夹爪 TCP 距离较远的问题。本项目希望改为左侧 / 右侧 / 上侧分布式 marker 布局，以降低机械包络、提升可见性并减小姿态误差向 TCP 位置误差的放大。

2. 设计范围

  • 设计夹爪端 marker carrier 的整体结构。
  • 设计 marker 安装面、定位基准、锁紧方式和防装反特征，例如非对称孔位、定位销、缺角或键槽。
  • 输出 URDF 文件，描述 carrier、marker 安装面、夹爪接口和相关坐标系。
  • 完成首批样件加工与装配验证。

3. 不在范围内

  • 视觉算法、相机标定、机器人 TCP 标定软件开发。
  • 夹爪本体运动机构改造，除非双方另行确认。
  • 量产工装设计，首版仅要求支持原型打样和小批验证。

4. 总体方案要求

项目要求说明
必须 同一刚体 所有 marker 必须安装在同一个非运动刚体上。 marker 可以分布在不同面，但各 marker 之间的 3D 相对位置必须稳定。
必须 固定安装 不得安装在随夹爪开合运动的手指、软壳、薄片或受力变形件上。 优先固定在 palm、手腕连接座或夹爪固定外壳。
目标 低包络 carrier 不应高于夹爪本体主要外轮廓；如局部必须高出，需要提前标注高度和原因。 目标是降低碰撞、出画和遮挡概率。
目标 短杠杆臂 marker rig 几何中心到夹爪 TCP 的距离目标 ≤ 100 mm，硬上限 150 mm。 距离越短，姿态误差传导到 TCP 位置误差越小。
必须 可重复装配 需要机械定位基准，不能只依赖人工目测贴合。 建议使用销孔、台阶、止口、沉头定位面等方式控制重复性。

5. Marker 布局要求

项目要求供应商需确认
布置面 至少包含左侧、右侧、上侧三个方向的安装面；marker 法线应非共面。 提供每个安装面的法线方向、尺寸和相对基准位置。
角度分布 相邻 marker 安装面法线建议间隔 60-90°。 若受夹爪结构限制无法满足，请提供替代角度与原因。
可见性 目标是在典型操作姿态下，每个主要相机方向至少能看到 2 个完整 marker。 我方可提供相机大致方位；供应商需在结构模型中检查明显遮挡和出界风险。
marker 尺寸 当前建议兼容 56 mm 黑框 marker；如使用其他尺寸，需先确认。 加工/贴附后需记录 marker 实测尺寸。
安装平面 marker 下方必须是平整刚性基材，避免纸张翘边、胶层不均、薄壁变形。 请给出推荐材料、表面处理和贴附工艺。
ID 管理 每个 marker 的 ID、朝向和所在安装面必须唯一记录。 交付 marker layout 表格和装配照片。

6. 结构与材料建议

  • 优先考虑 CNC 铝合金、刚性复合板或其他稳定材料。
  • marker 安装面应具备足够厚度和支撑，避免长期使用后弯曲。
  • 表面建议哑光、低反光；marker 周边避免高亮金属反光边。
  • 所有边角需倒角，避免划伤线缆、夹爪和被操作物。
  • 不得遮挡夹爪运动、线缆、传感器或原有安装孔。

7. 装配要求

  • carrier 应能在不拆解夹爪核心机构的情况下安装和拆卸。
  • 装配方向需有防装反设计，避免左右、前后或上下装反。
  • 紧固件需防松，且不得与夹爪运动件干涉。
  • marker 贴附或固定后不得翘边、起泡、明显偏斜或污染。
  • 如 marker 需要更换，应提供可重复定位方案或更换后的复检流程。

8. 关键验收指标

类别验收项目标 / 判据
机械包络 安装后不影响夹爪开合、抓取路径、线缆和周边机构。 全行程手动检查无干涉；关键姿态拍照记录。
高度 整体高度尽量贴近夹爪本体，不形成明显高位立柱。 供应商需在 URDF 备注或随附说明中标注最高点相对夹爪基准的高度。
刚性 正常装配和轻载接触后，marker 面无可见松动或变形。 拆装、轻触、复位后进行外观和紧固检查。
重复装配 同一 carrier 拆装 5 次后，定位应保持稳定。 我方会通过视觉和 TCP 标定复测；供应商需保证机械定位设计可重复。
marker 完整性 marker 表面平整、清洁、边缘完整，ID 和方向可追溯。 每件交付前提供清晰照片和 layout 表。

9. 交付物清单

交付物格式 / 内容用途
URDF 包含 carrier、marker 安装面、夹爪接口、坐标系命名和各 link / joint 的相对位姿。 仿真、视觉标定和系统集成。
mesh 文件 如 URDF 需要外部几何文件，请同步提供 STL / DAE / OBJ 等引用文件。 保证 URDF 可直接加载和预览。
Marker layout 表 每个 marker 的 ID、尺寸、安装面、朝向、相对基准位置。 视觉标定和质量追溯。
装配说明 安装步骤、扭矩建议、防装反说明、marker 更换流程。 现场装配和返修。

10. 打样流程建议

  1. 供应商提交初版结构方案、材料方案和预计加工方式。
  2. 双方评审包络、可见性、安装方式和维护方式。
  3. 供应商提交 URDF、marker layout 和报价。
  4. 加工 2-3 套首批样件。
  5. 我方完成装机、视觉跟踪和拆装重复性测试。
  6. 根据测试结果冻结设计或进入下一轮修改。

11. 需供应商反馈

  • 推荐材料、加工方式、表面处理和预计重量。
  • 关键安装面能达到的平面度、位置度和重复装配能力。
  • marker 固定方式建议，以及长期使用是否会翘边或脱落。
  • 是否存在夹爪干涉、装配困难或维护困难。
  • 首批样件周期、单件成本、小批量成本和最小起订量。

12. 设计禁区

以下方案原则上不接受：marker 安装在运动手指上；carrier 参与夹持受力；仅靠胶带或薄纸作为最终定位基准；高位立柱式结构；marker 面明显弯曲或可手动晃动；无法追溯 marker ID、方向和尺寸。
