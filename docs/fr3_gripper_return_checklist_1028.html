夹爪回来当天复核清单（F 线 · 10-28）

2026-10-26 写 · 对应 docs/dual_fr3_bimanual_replay_roadmap.html 的 F 线（F1–F7）

夹爪返修后，先确认它不再在腕部转动时掉电，再按「负载 → 夹持 → socket 常量 → 激光」逐层复核。每一步都写了判据和对比的旧数据：不过就停在那一步，别往后跑。

范围

  • 只涉及 right 臂（192.168.11.102，夹爪 BOX 596523097）。第二台 FR3 还没装（B1），所以「left 的第一次 pivot」、left 同球检验（F5）、双臂 Phase 12（F7）都不在这一天。
  • 手持侧：手持 BOX 和 cube 也一起送修了。它们如果同一天回来，做第 7 步；没回来就跳过。
  • 不需要：配重盘（Q4 不加工）；E 线直接在带夹爪的构型下做。
  • Connect、Execute、示教拖动都由操作者按或操作，工作半径内有人时不跑自动轨迹。

前一天（10-27）要准备好

  1. Thor 部署到包含 B2 的版本。10-26 起所有驱动 FR3 的入口都要选臂；Thor 上如果还是旧网关，GUI 不会有选臂框。部署前先 -n dry-run，看有没有 *deleting（多人共用 Thor 会互相覆盖）；只从主工作区部署；部署会杀掉 recorder，之后要重新 Connect。
  2. 确认 Thor 上有 tools/fr3/fr3_arms.json，网关 GET /api/robot/arms 能返回 right（在役）和 left（不在役，B1）。
  3. 两份 10-12 定稿的 Desk 末端配置在手边：~/文档/fr3+corenetic+cam_20261012b.json（无 SMR，0.9755 kg）和 fr3+corenetic+cam+smr_20261012b.json（有 SMR，1.1108 kg）。不带 b 的两份已作废。
  4. 第 5 步要用激光跟踪仪：确认采集 PC 上没开 RadianCAL-Pro（它会把实时流挤到每 5 s 只剩约 1 s）。跟踪仪断过电的话，Connect 时会依次报 13→43→22，这是冷启动流程，要等预热完成。

第 0 步 · 到货确认（5 分钟）

  • 问清厂家修了什么，特别是腕部转动时 BOX 重启（见第 1 步的历史）。有没有换线缆或接头？固件版本变了没有？
  • BOX 的 device id 有没有变。用 tools/thor/box_sdk/demo.py 做 discover，它会打印 fw 和 uptime。
    • id 仍是 596523097：什么都不用改。
    • 换了 BOX（id 变了）：fr3_arms.json 的 corenetic_device_id 和 replay YAML 的 robot.corenetic_device_id 要一起改。fr3_arms.validate 会拒绝两边不一致的登记，录制器也会把未登记的 BOX 当作手持 BOX。
  • 指尖型号：10-13 确认装的是「夹爪V2.1适配传感器指尖」。如果换了，第 3 步的尺量结果和 corenetic_socket_ee 常量都要重新确认。

第 1 步 · 腕部转动通断测试（F1，约 15 分钟）不过就停

为什么排第一：返修前同一个症状出现了 6 次，每次都发生在腕部转动时。BOX 掉电重启，约 2.2 s 后夹爪张开，插件就掉了。
  • 10-10：腕部掉电。
  • 10-13 16:35：pivot 中 j6 摆了 123°（89°/s）。
  • 10-13 18:10：引导 pivot 进行约 10 s、腕部正在转动时。
  • 10-20 14:03、14:40、14:45：都在 j7 以 2–3°/s 转动时。分别在 execute 开始后 5.0 s 和 42.1 s 开机；第三次在静止驻点，力只有 2.2 N。
开机瞬间的力是 2–3 N，比跑完全程的两次试探（最大 4.6–4.8 N）还小，所以不是力太大，而是腕部走线的问题。
  1. 装上夹爪，Desk 导入「无 SMR」配置。在 GUI 打开 ⓪ 夹爪遥控（打开期间 outputs/fr3_gripper_teleop*/box_sdk.log 会逐行记录设备时间戳，单位 µs、从开机算起），夹住插件。
  2. 记录开始时 discover 读到的 uptime_ms 和墙钟时间。
  3. 用 Desk 的示教/手拖模式，按下面顺序转腕部：
    • j7 全程来回 5 次：先慢（约 2–3°/s，就是出事时的速度），再快（约 30°/s）；
    • j6 大幅摆动 5 次（包括约 120° 的快摆）；
    • 再在 10-13 照片里的 pivot 姿态附近（j6 约 190–213°）转 j7。
    合计至少 10 分钟。注意：panda_py 的示教模式用 Panda 限位当虚拟墙（j2 ±101°、j6 ≤215°），越墙会直接 abort，所以用 Desk 自己的手拖。
  4. 结束时再 discover 一次。

判据：以下三条同时满足才算通过。

  • uptime_ms 的增量 ≈ 墙钟经过的时间（差 < 1 s）；
  • box_sdk.log 的设备时间戳单调连续，没有归零；
  • 夹爪宽度全程稳定在 ±3 mm 内（10-13 夹插件时是 34.8 mm）。

返修前每次腕部转动都在几秒到一分钟内掉电，所以连续 10 分钟不掉电是有意义的通过。

不过：停止所有 pivot 和 replay，把时间戳和姿态交给厂家。规则不变：任何一次 BOX 重启之后，都要先重新进入 ⓪ 遥控（mode 1）再放插件。重启后夹爪处于 mode 0，插件夹在指间时会反复开合。

第 2 步 · 夹爪模式会不会自己掉（约 5 分钟）

这是一个从来没验证过的问题：主机停止通信后，mode 1 和夹持目标会不会保持？数据流约 16 s 后就会老化。pivot 和遥控都依赖这一点。

  1. ⓪ 遥控夹住插件，然后停止遥控（脚本发 SIGINT，只补发最后一条命令，不设 mode 0）。
  2. 等 60 s，再 discover 看 mode，并量夹爪宽度。

判据：mode 仍是 1，宽度变化 < 1 mm。不满足就要记下来：pivot 和 execute 期间必须一直开着遥控，或者等 pivot 前检（BOX mode 和爪宽检查，10-13 提过、还没做）补上。

已知行为（不是 bug）：真机 replay 的 release_mode_on_disconnect=True，每次回放结束夹爪都会张开。

第 3 步 · 负载辨识与 Desk 配置（F2，约 40 分钟）

10-12 的两份配置是在返修前的夹爪上辨识的。返修可能换了零件，所以要重测。

  1. 先 fr3_move_to_start --arm right（collect 会检查 j1–j4）。
  2. 在 Thor 上用 .venv-fr3、PYTHONPATH=src 跑 fr3_payload_identification_runtime.py collect --arm right：32 个姿态，双向逼近（单向采集受关节静摩擦迟滞影响，结果作废，desk-config 也会拒绝）。无 SMR、有 SMR 各一次。
  3. fit，再用 desk-config 生成配置：不带零偏的拟合。机器人不扣关节零偏，带零偏的值会设得偏重——10-12 下午实测推翻过。

第 4 步 · socket 常量：逐夹持试探（F3，约 1 小时）

要回答的问题：每重新夹一次插件，socket 中心在工具系里移动多少？答案决定两件事：生产里的 corenetic_socket_ee 常量（= corenetic_gripper_ee + (0, 0, −10.3) mm，10-13 由端到端测得）能不能继续当常数用，还是每次夹持都必须先试探。

返修前的证据是互相矛盾的：
  • 同一夹持内拟合很好（rms 0.78–1.11 mm）；
  • 但 10-20 一天七次拟合，s_socket 的 z 从 −0.56 变到 8.77 mm；
  • 15:03 → 15:42 之间插件在夹爪里挪了约 5.6 mm；
  • 10-19 18:16 一次是 |s| = 8.7 mm。
此外，10-20 的 s 和 10-12 端到端之间的 14.1 mm z 差从来没分析过。
  1. 尺量：夹爪闭合时，量法兰面到传感器鼻尖的距离（10-13 实测约 175 mm，CAD 是 184 mm；URDF 指尖链沿轴比实物长约 9 mm）；再量夹住插件时的距离（端到端预测 173.9 mm）。这一步只要一把尺子，就能判断「连杆张开时指尖后退多少」（CAD 算 4.55 mm，端到端隐含约 1.1 mm）。
  2. 在 GUI 的标定中心 → FR3 球窝 pivot：⓪ 夹插件 → ① 取球心 → 「规划试探」（plan --probe：≤20°、6 个驻点、3°/s）→ 执行 → 网关自动拟合。试探完不要重新取球心，直接用同一个球心规划完整 pivot（自动勾选 anchor），再执行。
  3. 松开插件、重新夹，从「试探」开始重复，至少 3 次夹持。每次记录：夹爪宽度、s_socket、rms、转角跨度。

不要再做的事（返修前已经证伪）：

  • 从 F_ext 的压力负号推断「杯子在拽球」；
  • 把压入上限设成 3 mm（指垫会变形，试探实际需要 3.6–5.2 mm）。

第 5 步 · 激光核一次（F3 / E2，约 1 小时）

SMR 装到夹爪上，Desk 和 fr3_arms.json 的负载登记一起切到「有 SMR」。起始姿态时让 SMR 开口正对跟踪仪：10-10 三次丢光都发生在接收锥边缘。

  1. 同一条 episode 用 lead 3 做真机回放两次，再用 Episode Replay 页的「Laser vs FR3 Replay Error」面板分析。
  2. 如果有带激光的录制段（参照 10-13 的 thor_gmsl2_10ch_v1_20261013_110115 ep0），再做一次端到端对比。
