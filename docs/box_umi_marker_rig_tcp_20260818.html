「定点摆动」的操作定义（这次没做对的地方）：rig 的球窝始终坐在桌面固定钢球上不离开， 手只改变 rig 的朝向。要稳住的是球窝球心，不是 rig 的几何中心 —— 5.2 节记录的第三次尝试正是稳错了点。判据首选 |p_rig| ≈ 1 mm（见 5.2 节的即时自检）； 球心位移包络 <20 mm 只是辅助粗筛（成功的两次实测 4.3–11.1 mm，本次是 547–940 mm，中间没有灰区）。 姿态跨度这次是够的（35–45°）。 注意这不是「要手很稳」的要求：把球心钉住的是球窝-钢球的接触本身，不是手；见下面 5.1 节的容差实验。
「挪位置」挪的是哪个：是桌面上那颗钢球（连底座），即支点在 base 系的位置 q_base。rig 底部的球窝是打印件的一部分，跟 rig 一起走，本来就动不了； p_rig 是被求解的交付量，按定义与钢球摆在桌上哪里无关 —— 判别实验要的正是 「换个 q_base 后它复不复现」：复现（差 ≲0.3 mm）则那 0.9 mm 跟着 rig 走 = 假设 (A) 装配/打印； 随位置跳变（~1 mm 且方向随位置变）则来自 base 系里的场 = 假设 (B) 相机外参。 之前两次采集的 q_base 只差 1.44 mm，等于同一个位置，所以给不出结论； 新位置建议横移 0.3 m，且仍落在 x 0.7–1.1 / y −0.3…+0.4 / z 0.45–0.65 m 内。

5.2 第三次尝试（…_180914）：稳住的点选错了，但换来两个结果

这次是「marker rig 中心尽量保持不动（约 <1 cm 晃动）」。数据本身很干净 —— 1218/1218 帧全部解出融合位姿、7 台相机、残差 p95 3.64 mm、姿态跨度 p95 80.4°，都和两次合格采集同档。 操作也到位：被盯住的那个点确实稳到了 7.00 / 11.12 mm 包络，正是「<1 cm」。

但稳住的不是球窝球心。CAD 系 layout 下拟合出的定点在 [114.0, 1.7, −1.5] mm （离球心 114 mm、离 marker 几何中心 45.7 mm），而球窝球心自己的轨迹包络是 221.9 mm —— 球窝全程不在钢球上，转的是手扶住的位置。判别实验必须以球心为定点，因为只有那里的真值是 [0,0,0]；手扶点没有真值，|p_rig| 就不再是误差度量。

6.1 更正：拟合残差几乎没降，而且本来就不该降

本文档早先把「拟合 p95 3.76 → 3.02 mm」当成改善写了出来 —— 那是跨口径比较：3.76 出自生产链路， 同一估计器跑 0812 原始数据得到的是 3.19。同口径的 A/B 因此是 3.19 → 3.02，几乎没动。原因有两层。

其一，残差不是 L·θ。逐帧残差是 r_i = δt_i + δθ_i × (R_i·p)，只有第二项与杠杆臂成正比。 把残差除以杠杆臂换算成等效角，反而涨了：

杠杆臂残差 p50 / p95残差 ÷ 杠杆臂（等效角）
0812 cube（同一估计器）240.4 mm1.09 / 3.19 mm0.259° / 0.760°
0818 新 rig102.3 mm0.84 / 3.02 mm0.469° / 1.693°

杠杆臂缩了 2.35×，等效角涨了 1.8×（p50）到 2.2×（p95），乘起来抵消。 也就是说残差已经不再由杠杆臂主导，而是由与杠杆臂无关的项主导。

其二，那个「与杠杆臂无关的项」就是 layout 误差。老 cube 的角点由「理想立方体 + 实测边长」解析生成，刚性上完美； 新 rig 的 layout 是从数据里量出来的，角点刚性 p50 0.91 / p95 6.45 mm。layout 有误差时位姿就依赖于 「这一帧看见哪几个 marker」，marker 集合一换位姿就跳 —— 而这恰恰是帧间一致性残差唯一看得见的那类误差 （rig 系里恒定的误差会被 p_rig 整个吸收，这也是 0812 文档「系统项残差里看不见」的同一条道理）。 按可见集合切分，信号非常干净：

按相机数切分同样：3 相机 p50 3.52 / p95 5.08，5 相机 p50 0.72 / p95 1.41。全局 p95 的尾巴里 87% 来自 ep4， 因为 ep4 低相机数、丢 marker 的帧最多 —— 不是座子被碰动（原第 7 节第 4 条的猜测）。

在相机数匹配的条件下比（5 相机）：0812 是 0.96 / 1.86 mm，新 rig 是 0.72 / 1.41 mm，改善约 25%。 杠杆臂的收益是真的，但它体现在精度（逐相机分歧投影到 TCP，6.32 → 2.59 mm p95），不体现在拟合残差； 残差现在被 layout 质量卡住。这也正是转向 CAD 约束 layout（2.3 节）的直接动机： 用 CAD 冻住板心与法线之后，0818b 的残差 p95 从 2.60 掉到 1.92 mm，holdout p95 从最差 4.75 掉到 2.09 mm。

对照实验的一个已知瑕疵：它用 cv2.aruco 检 36h11，而不是生产用的 pupil 检测器（本机 venv 未装）， cam_13 / cam_14 上出现了会污染单相机 PnP 的误检（自身重投影中位 179 / 183 px），因此该行的 「逐相机最大两两」不可用（504 mm）。融合解不受影响 —— corner-BA 的重投影门限把这些帧挡在外面， 这也是上表 p_cube 仍能复现公开值的原因。

7. 还不能交付什么

未决
  1. rig → TCP 的旋转仍差最后一步语义。CAD 已经给出 rig 系与 CAD 系之间完整的 6D 变换（中心对齐残差 0.93 mm）， CAD 原点就是球心 = 未来接触中心；但「CAD 的三根轴对应夹爪 TCP 的哪三根轴」还需要在 rig 真正装到夹爪之后确认。 0812 已经栽过一次：单点 pivot 永远给不出旋转，任何旋转都必须写明 rotation_source。
  2. 接触中心 ≠ TCP_closed。0812 的口径里，pivot 测的是两指腹中心，到 TCP_closed 还要沿手指轴修 −20.04 mm（FK 指腹中心偏置，机构状态 d = 34.27 mm）。本次 rig 不在夹爪上，这一段还没有对应实物。
  3. 重复性只做了一半。「同一装配、间隔 1h45m 的重扫」已完成，两次差 0.60 mm（2.3 节）； 但拆装 5 次、不同 opening、轻载荷方向仍然一组都没做。现在这个 102.3 mm 依然是单次装配的值。
  4. ep4 的 holdout p95 = 4.75 mm 需回看视频 —— 已定位，不是座子被碰动： ep4 低相机数 / 丢 marker 的帧最多，全局残差尾巴的 87% 来自它（6.1 节）。换用 CAD 约束 layout 后， 三条 holdout p95 收敛到 1.83 / 1.87 / 2.09 mm。
  5. layout 求解对坏相机没有防护（新增，见第 5 节）：它对全部相机等权做像素级 BA， 一台外参错的相机（cam_09）就能把杠杆臂推偏 5 mm。跟踪端有 8 px 逐相机门限，layout 端没有 —— 应补上同一道门。
  6. marker 7 / 17 的 layout 较弱：它们平均只有 1.9 台相机同时看得见（其余三个是 3.4–4.8 台）。 CAD 约束 layout（2.3 节）已经把这条从「误差源」降级为「无所谓」，因为它们的位置不再由射线交会决定； 但如果要回到纯数据自定义 layout，这仍是首要短板。
  7. 1.3 mm 系统偏移的成因 —— 已定位：卡尺（贴纸实测 60.86 mm）判掉了尺度与 marker 尺寸两个候选， 偏移几乎纯切向，是打印件板位相对 CAD 的横向装配公差。改用 CAD 先验后降到 0.90 / 1.03 mm（2.3 节）。
  8. 剩下的 0.9–1.0 mm 是装配项还是相机外参项 —— 已判定为装配项（5.3 节）： 球窝位置搬 0.3–0.45 m 后 p_rig 只差 0.38 mm、方向差 9.5°，比原地重复还一致， 所以偏移固定在 rig 系。跨三个球窝位置合并后 |p_rig| 降到 0.54 mm。 剩下的分解：仍未拆开的是那个 0.73 mm 位置相关零均值分量（同位置 ep 间散布 0.42 mm， 跨 0.45 m 涨到 0.84 mm；n=3 且姿态覆盖不同，属提示性），以及球窝间隙 —— socket R=12.68 对 25 mm 球， 球心落在窝里哪一点由受力方向决定、而受力方向随 rig 一起转，是姿态相关项， 极端两点 0.36 mm × 1.22 倍杠杆 ≈ 最多 0.44 mm 进 p_rig 且残差看不见（5.1 节； 此前本文写它「只进残差不进 p_rig」是错的）。判别仍然很便宜： 两次采集故意用不同的按压方向，p_rig 若差 0.3–0.4 mm 即坐实。
  9. cam_09 / cam_08 必须重标。它们在第二次采集里失效（第 5 节），当前所有最好结果都是把 cam_09 排除在 layout 求解之外得到的； 这不是长久之计 —— layout BA 需要一道逐相机重投影门限。
  10. 生产链路还检不到这个 rig。生产配置是 36h11 + cube 面解析角点；接入前需要把 marker_layout.json 与 ArUco 字典打通（roadmap 已列为 P0-1「marker layout 可标定化」）。
