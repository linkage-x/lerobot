01 · 为什么现在值得做

实现进度：浏览器端配对仿真器已完成 M0 数值检查、M1/L1、MC-lite 和 L2 图像 pilot。新增逐像素鱼眼射线渲染、真实 ArUco / Hybrid 检测、统一多相机 BA；页面可切换预测与图像误差，查看配对 Δp95、区间、全帧 CDF、达标率与失败率。缺 measured R0、冻结生产相机/任务和完整 L3 证据时保持 Inconclusive。运行方法与当前边界。

主路线图的 v18.0 / v18.1 已明确：0907-on-gripper 当前 No-Go，先做同轨迹 visibility / FIM / TCP covariance 比较。本计划将这条决策展开为可执行实验，并补上仅看 FIM 无法回答的失败率、系统偏置与总误差问题。

现有证据允许得出的结论仍不能推出什么
A′ p95 ≈3.8–4.0 mm这是当前 rig 口径的工程预算参考；它包含历史统计与外推。不是独立 GT 实测，也不能作为这次仿真的固定“真值”。A = 7.43 mm 为逐相机弥散诊断量，不能与它拼成精度区间。
主路线图对 0907 的收益预估 ≈0.43–0.46 mm已有机理支持的改善不足以直接覆盖目标差额，值得先做低机械成本筛选。3.35–3.52 mm 的“实际点”与 2.55–2.69 mm 的“理论地板”都是预算情景，不是新仿真结果，也不是硬物理极限。
0909 carrier 实机可解检测器与多相机链路能够工作；可用来核对投影尺寸、检测数量和噪声量级。与 0818 / 0821 的速度、外参、几何和筛选均不相同；≥3 anchor 对 0907 是全见，对五 marker rig 是部分可见，不能据此宣布成倍提升。
已有 render → detect A/B可复用同 seed、几何真值与求解模型分离、去除彩色面、遮挡和曝光运动的实验框架。默认单相机 pinhole、理想标定、简化遮挡；它不能直接预测七相机 fisheye 生产 TCP 的总 p95。
实验的价值是辨别收益来自哪里：更好的 3D 布局、更多可靠图像信息、更稳的检测，还是仅仅修正了贴纸尺度／装配误差。即使结论为 No-Go，也能避免把机械开发投入一个只改善随机噪声、却碰不到主导偏置的方向。

本分支不取代相机状态监测、真实 marker→TCP 测量或独立 GT。刚性一体化仍有价值；它不等于必须采用 0907 的具体几何。无需先搭建双 FR3 动力学或接触仿真，当前需要的是相机测量链 + 靶标几何 + 任务遮挡的离线仿真。

03 · 公平比较的输入契约

同一个物理 TCP 走同一条轨迹

约定 T_A_B 将 B 系坐标变换到 A 系。对每个候选冻结 T_TCP_rig，由任务的 T_world_TCP(t) 生成各候选真值：

T_world_rig(t) = T_world_TCP(t) · T_TCP_rig
T_world_TCP_est = T_world_rig_est · T_rig_TCP

0818 的数据自定义 rig 系可能带约 102.3 mm TCP 偏移，而 CAD 球窝系可以把 TCP 放在零点；0907 也可以以球窝为零点。改原点不会增加观测信息。应在同一个物理点上比较，不比较两个任意模型原点的位置误差。

同一相机、任务与环境扰动

主实验使用冻结的七相机 cam_06/07/08/09/12/13/14 配置、相同分辨率、fisheye 模型与曝光。内外参需来自同一快照并记录内容哈希；不能按“当前路径”动态读取。

轨迹来源包括真实 manipulation 的姿态与速度分布、工作区覆盖扫描、独立生成的连续 SE(3) 压力轨迹。真实估计轨迹只用作任务分布代理；仿真误差参考是显式设定的真值，不是原来的视觉标签。

  • truth 与 estimator 分开：几何、K/D、相机外参、时钟分别保留真值和求解输入两份对象。系统误差试验只改变其中一侧；一起改会把误差抵消。
  • 公平安装空间：先做 socket-TCP 现成结构对照，再做 gripper contact-TCP 候选安装对照；第二组显式建模实际安装旋转、偏移、包络及开度依赖，不能把球窝原点直接等同于夹爪接触点。
  • 制造状态分组：nominal/nominal 用于设计潜力，measured/measured 用于当前物体，measured/nominal 用于公差敏感度。双方使用同等级几何校准，禁止只给候选“完美 CAD”。
  • 训练／验证分离：安装方向优化、噪声拟合、阈值调参只用开发集；最终比较用未参与调参的 episode、姿态、遮挡和 seed。缺失输入记为待补，不用默认值悄悄代替。
  • 采集完整性：按 episode ID 配视频和行；仅视频、无 BOX 行的数据可用于图像检测研究，但不能伪装成完整多模态训练轨迹。0909 的两个可用 episode 共 2403 行只是已知证据，当前不向 Thor 发起读取或作业。

04 · M0：先证明模拟器没有把答案写进输入

浏览器 M0 核心已实现 已核对描述符哈希、贴纸转角、坐标／单位、统一 fisheye 投影、实体遮挡、相关 edge 降权与奇异 FIM。新增真实 ArUco 解码对照、R0 绕序反例和 TCP 协方差坐标不变性测试。缺失 measured R0、生产相机快照和真实任务轨迹继续阻止 G0；完整图像域的超采样收敛阈值尚待冻结。

已核查到的代码状态本实验必须补的检查退出条件
hybrid_carrier_render.py 默认从空映射取转角 0；0907 描述符却固定 [3,3,2]。默认 A/B 调用没有显式传入这一映射。按真实贴纸 corner 编号独立构造预期投影，覆盖三个非零 quadrant、镜像错误和法向翻转；修正默认值或显式传值并记录。无噪声的已知位姿测试通过；故意错贴或读错描述符的反例确实失败／报大误差。不能只断言 success=True。
旧 compare_fiducial_targets.py 是单 pinhole 相机；方形贴纸采用平面 homography 粘贴。多相机 fisheye 渲染须做逐像素射线／纹理映射或经过验证的成像重映射。鱼眼图上的平面贴纸一般不是严格四角 homography。中心与边缘、近远距离的角点及边上采样与独立投影一致；亚像素误差阈值先由超采样收敛试验冻结。
evaluate_marker_layout_fim.py 主要做深度、画幅、有效半径检查；Level 3 另有朝向／尺寸门限。都不足以替代完整遮挡场景。加入表面正反面、自遮挡深度、支架／手／夹爪／物体遮挡与部分贴纸可解码性；从 CAD 显式读取法向，不能对非凸支架只靠“朝向原点外侧”猜。已知遮挡场景有预期可见集；隐藏特征不再贡献 FIM。支持架缺 mesh 时报告上下界，不给实际 coverage 结论。
旧比较汇总主要报成功样本 p50/p90，失败计数另列；同边多个样本可能相关。保留每个试次、失败原因、错误接受、完整协方差与边 ID；引入相关残差及姿态误差检验。奇异信息矩阵判为弱观测；增加同一条边的重复样本不会虚假地把 σ 压向零。
必须有两个独立基准：① 解析投影／有限差分 Jacobian；② 已知世界 TCP 的图像级真值。渲染器与检测器共用错误 corner 顺序、尺度或变换时，round-trip 可以自洽却同时出错。坐标变换、单位 m/mm、K/D 系数顺序和零点平移均要有反例验证。

05 · 三层仿真，各自回答一个问题

M0锁输入与验证模拟器
L1几何、可见性、信息量
L2图像、检测与失败尾部
L3联合系统扰动与轨迹
M4分层证据与开发决策

L1 · 条件精度下限：布局到底有没有优势

在真值位姿、正确对应关系与冻结的观测噪声模型下，合成可见 anchor 角点和 edge 法向残差。使用完整遮挡后的约束构造局部信息矩阵；先 R0 ↔ H0，再 H0 ↔ H1。边样本只提供法向距离约束，不当作一个完整二维角点。

F = Jᵀ Σimage−1 J
Cpose | calibration, geometry, correspondences ≈ F−1
σTCP,worst = √λmax(CTCP,translation)　[mm]

它是给定噪声、正确局部解与可见性下的预测。CRLB 解释还要求相应统计模型与正则性；鲁棒求解器输出的逆 Hessian 不能自动称为全局误差下界。协方差计算的白化与秩条件参见 Ceres 官方说明。

  • 同时输出位置／姿态信息、最弱方向、规范化 Jacobian 的条件数与有效秩；用声明的长度标尺归一化 m 与 rad，禁止拿带混合单位的条件数做跨 rig 排名。
  • 协方差奇异时标记不可观测；伪逆在零空间得到的数不能当作“零不确定度”。FIM 检不出相距很远的 PnP 多解，后者交给 L2。
  • 输出 p95_over_poses(σ_TCP,worst)，明确它是“不同姿态的预测标准差分布”，不叫“TCP error p95”。
  • 边噪声至少比较独立模型、同边共模偏移模型和保守下采样模型；同一标记的角点也允许相关。若收益仅存在于把数百边像素当独立样本的模型，判为未证实。
TCP 传播：保留平移—旋转相关，避免 L·θ 重复记账

固定采用局部参数 δξ=[δt_world, δθ_world]，其中位置在 rig 原点加性扰动，旋转为左乘扰动。令 p_world_TCP=t+R p_rig_TCP：

JTCP = [ I　−[R prig_TCP]× ]
CTCP = JTCP Cpose JTCPᵀ

其他 SE(3) 扰动约定需先换 Jacobian。保留 C 的交叉块；安装／TCP 本身不确定时扩大随机变量并传播其联合协方差。不要再添加独立的 (L·θ)²。把模型原点从 feature 质心移到球窝后，正确变换协方差应得到相同物理 TCP 误差；把这条坐标不变性写成检查。

L2 · 渲染与真实检测：理想信息能否被稳定读到

用冻结 detector 与生产 solve / gate / fallback，在同一组多相机合成帧上完整运行。R0 使用实际 layout 的 ArUco 路径，H1 使用当前 Hybrid strategy；各自保留原生行为，同时有统一 corner BA 的受控对照。曝光用连续位姿的时间积分，明确标签对应 SOF、曝光中点还是其他时间基准。

  • 同时建模贴纸像素尺寸、入射角、fisheye 边缘、光照／白平衡、反光、边线宽度、光学模糊、噪声与背景相似颜色。输出误检 ID 和错误 corner 对应，不把它们并入普通高斯角点噪声。
  • 分别做无历史冷启动、正常连续跟踪、丢失后重捕获；每个目标独立维护种子，禁止跨目标／episode 传状态，禁止用真值初始化正式结果。
  • 重点检查 0/1/2/3 个可解码 anchor、强遮挡、错误 PnP 分支与细化失败。局部 residual 或 σ 小并不保证选对全局位姿。
  • 颜色带来的假设排序变化与 edge refinement 分开记录。对“有 anchor 就跳过弱约束检查”的路径做显式消融，不只测试 anchor-free 的安全门。

L3 · 系统扰动与时间序列：能否改善任务 TCP 总误差

在明确的仿真世界中分开“真实相机／实物”和“求解器认为的相机／模型”。先单源定位，再联合抽样重跑真实解算，最后按相同参数运行 raw BA 与 offline smoother 两条输出。用联合误差样本直接计算分位数，不能对各来源 p95 做 RSS，也不能沿用历史 0.85–0.895 修正因子。分布传播方法参考 BIPM JCGM 101:2008。

扰动来源抽样层级与相关结构能否归功于换靶标
角点与 edge 定位帧／特征随机项 + 同 marker／同 edge 的相关项；按像素尺寸、角度、模糊分层拟合。可以，但只能用实测／验证过的噪声变化；不要预设彩色边一定更准。
K / D / 外参每个虚拟 session 抽一次并跨帧保持；区分相机独立偏差与网络共模。联合采样 K/D；不能独立随意抽 fx/fy，忽略已知相关。靶标可能改变对偏差的敏感度；相机本身的偏差不会因换靶标自动缩小。
尺度、几何与安装本体尺度与贴纸绕自身中心的尺度分开；增加贴纸位移、转角、翘曲、facet/墨线偏移、重装安装偏差。每件／每次安装固定，必要时加入载荷或开度相关形变。必须比较等等级制造条件。rig 原点等于 TCP 不会消除尺度、安装与实物形变误差。
时间与运动相机间 SOF skew、Camera↔BOX 标签偏移、曝光积分分别建模；session 偏移与 frame jitter 分开。同速度同 Δt 的标签错时不由换靶标消失；运动模糊造成的检测退化可不同。
共模 world 变换／尺度对整个相机网络注入可解释的确定性偏差，不给参考轨迹做自由对齐来抹掉它。两种靶标可能同受影响；用于展示误差地板。情景量级没有出处时只报敏感度。
平滑与缺测连续轨迹上使用同一平滑策略；保留急停、换向、接触与缺测段，并测滞后和填补误差。是共同下游模块；只有基于各自原始观测的联合重跑，才能计入靶标带来的间接收益。

每个扰动值附 source / units / distribution / correlation / sampling_scope / evidence_status。缺少可测分布时，用低／中／高压力情景并明确标为假设，不把情景权重伪装成真实发生概率。不要为“复现约 4 mm”倒调噪声。

06 · 实验矩阵：先任务域，再压力边界

维度第一轮扩展与约束
工作区 / 姿态相同历史 manipulation 轨迹的分层采样；加独立空间网格与 SO(3) 姿态。保留真实时间权重；压力网格单独统计。不能用“正对每种靶标的最佳视角”分别出题。
可见相机七路完整；逐一掉一路。21 组掉两路、仅 2–3 路压力测试。按相机身份分组，不能只按数量汇总。
遮挡真实夹爪／支架静态几何；手部用可调胶囊／网格包络；常见操作物体。0/15/30/45/60/75% 图像遮挡作为诊断阶梯。同一世界遮挡物对不同靶标的遮挡比例可不同，主 A/B 不能强制改遮挡物使两者比例相等。
运动任务静止、低／中／高线速度与角速度分层；覆盖历史约 680 mm/s 高速区。曝光按真实元数据范围扫；以 m/s × s 生成模糊而非仅任意 smear-mm。急停、换向和相机集合切换不可被均匀抽帧漏掉。
几何 / 外观双方 measured 与 nominal；H0/H1 使用同一图像的 edge-off/on 对照。贴纸尺寸、facet 墨边、背景同色、反光与手部误着色等单因素扫描，再测少量关键交互。
模型误差零偏理想、已测采样噪声、会话固定偏差三个等级。单相机被碰与共模偏差单列；先按测量来源冻结范围，缺 D 协方差时保留未知项。

计算规模分级：先 100–200 个姿态做正确性与性能 pilot；L1 再扩到约 1,000 个任务／压力姿态；L2 用 200–400 个分层姿态起步并补连续片段；L3 先 200 个 session 级配对扰动，再按关键指标的区间稳定性追加。以上是起步配置，不是统计充分性保证。缓存几何、可见性和静态纹理，先计时再决定 worker 数，不执行所有维度的笛卡尔积。

07 · 结果必须让“更准”和“少报难帧”分得开

指标组必须报告统计口径
TCP 真值误差平移范数与 SO(3) 角误差的 p50/p95/p99/max；按速度、遮挡、位置和相机子集分层。绝对模式不逐 episode 做自由 SE(3) / Sim(3) 对齐；先报告 raw，再报告 smoother。
coverage / yield几何可观测率、detector 出姿态率、生产门控接受率、真实误差在 3 mm / 0.5° 内的比例。分母都是预注册的所有请求帧。失败与拒绝不能从统计账本消失；部署可检测的 valid 与仿真真值判定的 accurate 分开。
公平误差比较两者共同成功帧上的配对误差；双方各自成功集；各类失败率；固定全帧分母的达标 CDF。共同成功集不能单独作为胜负依据。可将未返回位姿记为 +∞ 的全帧误差用于补充评价，同时单列失败，不编造有限惩罚误差。
粗差与错误接受超 3 mm / 0.5° 为超标；超 20 mm 或 5° 为本实验提议的 catastrophic 阈值；区分拒绝和自信地接受错误。阈值在 pilot 后、正式盲测前冻结；reported σ 小且真值错误大必须单独计数。原主线不同粗差阈值仅作对照。
轨迹局部质量40 / 100 / 400 ms / 1 s RPE、缺失持续时长、重捕获延迟、急停与接触区误差、jitter。按 timestamp 配对、不跨 episode；coverage gap 不插值成真观测。静止 jitter 小不意味着绝对误差小。
不确定度可信度预测置信椭球覆盖率；在相同切空间用 NEES 检验协方差与真值误差是否匹配。理想正确模型与含系统偏差分别评价；非高斯／多模态失败另报，不用一个缩放系数掩盖。
代价每相机帧与联合帧耗时、p95 延时、重捕获峰值、内存；机械包络、突出和任务遮挡。不把“更多耗时换更小误差”隐去；本阶段评估离线标注，不自动要求实时控制频率。

主差值定义为 Δp95 = p95(e_R0) − p95(e_H1)，不是 p95(e_R0 − e_H1)。用相同任务与外部扰动 draw 做配对 bootstrap，按 session / episode / 连续时间块重采样，避免把相邻帧当独立试验。独立生成噪声的附加复核用于确认结果不依赖某个随机耦合方式。

罕见灾难不能用一段连续 2403 帧的“零次失败”证明消失。只在近似独立试次下，零事件的 95% 发生率上界才可粗读为 3/N；时间相关、场景单一时需扩大独立场景与 episode，而非只补相邻帧。

08 · 修订 Go / No-Go：从预测 σ 到实际收益必须有证据链

保留主路线图“值得机械开发需要约 0.8 mm 以上收益”的工程意图，但将 FIM 筛选与总误差判决分开。原文“TCP translation covariance p95 下降 30–40%”没有指定矩阵标量、单位和分位数对象，不能直接作为最终开发 Gate。

为什么协方差改善不等于总误差改善

下列是零均值、独立分量的单轴方差示意，不是本项目的误差预测；系统偏置、多模态与实际 p95 不按它换算。默认：可改善项方差减少 35%，却只占总方差 20%。

3.6%总标准差下降

σ_component,new / σ_component,old = √(1−r)；σ_total,new / σ_total,old = √(1−a·r)。因此“方差下降 30–40%”本身只对应该项 σ 下降约 16–23%。

Gate通过条件不通过时
G0 · 结果可解释坐标／转角／遮挡反例、独立投影和噪声验证通过；双方输入、安装候选、采样与阈值冻结。修模拟器或补输入；结论是“实验不可判”，不是某个靶标 No-Go。
G1 · 有值得继续的优势在任务域看到可重复的 TCP σ／姿态改善，或检测／遮挡收益有独立证据。若采用 σ 改善 30% 作筛选，必须明确写成 p95_over_poses(σ_TCP,worst)，仅作规划代理。若几何无明显收益且检测无优势线索，停止扩展。FIM 单项不优但存在可检出性收益时，仍允许做有限 L2 反证。
G2 · 条件 Go：值得做机械样机经 L2/L3 可信模型，在预注册任务域上配对 Δp95 的 95% 区间下界 ≥0.8 mm；并且 H1 的模拟 TCP p95 ≤3 mm、旋转 p95 ≤0.5°。总 coverage 达到主线 >99% 目标且相对 R0 不降低；高速／遮挡关键桶不反转。若基线有足够事件，弱／灾难帧至少减半，错误接受率不升高。这是严格工程立项门槛，仿真通过仍非真实精度认证。统计事件不足或输入分布不可信，转“证据不足”，不能宣布 Go。
No-Go · 停止 0907 geometry 分支可信联合情景只支持约 0.3–0.5 mm 收益；或保守边相关／真实遮挡一加优势消失；或恶化高风险尾部。保留 rig0818 或设计更简单的 rigid integrated carrier；继续处理相机、尺度与安装问题。独立的检测器研究不因几何 No-Go 自动停止。
Inconclusive · 定向补测区间跨过 0.8 mm、手部几何未知、D/安装偏差没有来源，或结论随合理情景反转。只补最能改变决策的一项数据；例如手握包络、贴纸边长或边相关噪声。不要无目标地扩大全矩阵。

G2 数值是本路线图建议的决策规范，尚未执行验证。收益 ≥0.8 mm 不保证从 4.0 mm 降到 ≤3.0 mm，所以同时检查候选绝对值；仿真基线若不代表实际工位，只能宣布“该情景下成立”。若机械包络／遮挡改善很大但精度未过 G2，应另立包装／可用性目标，不改写精度结论。

10 · 最终报告应长什么样

  1. 一页决策：Go / No-Go / Inconclusive，作用域、基线与候选版本、结论成立的噪声／机械条件。
  2. 三套互不混算的图：L1 的预测 σ 地图；L2 的全帧成功／超标／粗差 CDF；L3 的模拟 TCP 总误差与配对 Δp95 区间。
  3. 归因表：R0→H0 的 geometry 收益、H0→H1 的 edge 收益、原生检测行为收益；manufacturing、安装和标定修正独立列账。
  4. 场景审计：每个关键桶的总帧数、独立 session 数、失效数、拒绝数、图像投影尺寸、真实可见集及重复边样本有效信息量。
  5. 反例页：至少展示最差姿态、重遮挡、错误转角、鱼眼外环、错误 PnP 分支、相机集合切换和共模偏置；附可重放 seed 与 truth。
  6. 复现包：输入内容 SHA-256、相机和模型版本、dirty patch、依赖版本、完整配置、原始逐试次表、命令与机器资源；所有随机 draw 可追溯。

若条件 Go，真实验证最少需要：同日、同一相机快照、可重复参考轨迹；相同操作遮挡与速度分布；独立 TCP 位置／姿态参考；重装、开度、载荷和跨日复测。论文中可先报告受控仿真机理与失败边界，但“实机毫米级精度”和“优于 rig0818”必须分别取得对应证据。
