成像：七台声明式相机使用 OpenCV 等距鱼眼多项式。角点数值 Jacobian 与页面可见性调用同一投影。

边：H1 的每条 CAD edge 只贡献图像法向一维残差；同边样本按 n_eff = n/(1+(n−1)ρ) 降权。

配对：三个 arm 共享真值、遮挡、相机、时序、共模偏差与标准正态 draw。安装误差使用同等级分布和配对抽样。

区间：Δp95 = p95(R0) − p95(H1)，只在双方共同成功帧上计算，并按连续 episode 整块 bootstrap。覆盖率仍以所有请求帧为分母。
