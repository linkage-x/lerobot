01

这份文档要解决的问题

先说清楚我们在做什么，否则后面每一条约束都会显得过分。

人手持 BOX（夹爪 + 传感器）做演示操作，桌面上 7 台固定相机通过夹爪上的 marker 反解出夹爪的位姿轨迹， 这条轨迹被当作训练数据的动作标签，随后要在双臂 FR3 机器人上复现。 标签错多少，机器人就学错多少，而且下游没有任何环节能把它纠正回来。

现在的状态：纯相机侧（把 marker 当作刚体目标）的误差 p95 约 4 mm， 距 3 mm 目标不远；但真正进训练集的那条路径给不出可信数字， 因为从 marker 到夹爪 TCP 的那一段常量既没有被完整测量，装配本身的重复性也从未被测过。 这一段是机械件，不是算法，所以它是这次设计的核心。

为什么必须重出一版，而不是在现有夹爪上改

2026-08-21 同时出现了三件事：一只夹爪的 marker cube 明显晃动；另一只 cube 安装位置被改变； 中间一个版本把 cube 前移以缩短杠杆臂，结果前向 marker 被相机本体挡住。 第三件事是最值得记取的：它用 1–3 mm 的 marker 观测损失，换来杠杆臂的一点线性缩短，净亏。

结论是：marker 的安装几何不能作为夹爪设计的附属品事后处理，它必须和夹爪本体一起设计、一起冻结。 这也是我们在新夹爪到货前暂停做拆装重复性测试的原因——在旧装配上测出来的分布不会迁移到新设计上。

02

四条会直接决定精度的物理机制

这一节不含要求，只解释原理。理解这四条以后，第 3–5 节的每一条约束都能自己推出来。

一 · 杠杆臂把角度误差放大成位置误差

TCP 位置误差 ≈ L × θ

marker rig 几何中心到夹爪 TCP 的距离 L 就是杠杆臂。视觉解出的 rig 姿态有一个残余角度误差 θ， 它经过这条杠杆变成 TCP 的位置误差，而位置误差才是我们的指标。

实测：rig 自身的姿态分歧 p50 0.64° / p95 1.50°。 在旧高位 cube 的 241.5 mm 上，这是 TCP 上的 2.69 / 6.32 mm—— 已经吃掉 3 mm 预算的大半。把 rig 压到 102.3 mm 之后同样的姿态误差只剩 1.20 / 2.59 mm。

关键点：姿态精度几乎没变（0.64° → 0.67°），变的只是它被乘以多长的杠杆。这是纯机械收益，算法买不到。

二 · 可见性决定有几台相机在解这一帧

看不到 = 这台相机这一帧不存在

marker 必须四个角点完整落在画面内才算一次观测。高位 cube 同时触发两种失效： 越出视野上缘（cam_09 丢 47.4% 的帧，其中 96% 属于此类）， 以及被手臂/物体遮挡（cam_06 丢 24.2%，全部属于遮挡）。

相机数减少不只是"稍差一点"：解算尾部误差几乎全部来自弱几何帧——只有 2 台相机参与的帧占样本 8%， 却占了误差最差 5% 的 38%。

低矮分布式布局把最差相机丢帧率降到 14.3%，是同一个设计改动的第二项收益。

三 · 松动是系统性的盲区，不是"噪声大一点"

共模误差 = 所有自动检查同时失明

如果 marker 相对夹爪会晃动，我们所有的质量检查都查不出来： 多相机一致性看不见（7 台相机看的是同一个晃动的 rig，晃动是共模量）； 重投影残差也看不见（残差只说明"这些角点自洽"，不说明"它在夹爪上的位置对"）。

后果是数据表面全绿而标签是错的。我们已经据此定了一条硬规则：装配恢复刚性之前采集的数据一律不进训练集。 也就是说，一处松动会作废整批采集，而不是让它精度降一点。

所以刚性不是"越硬越好"的目标项，它是一条通过/不通过的门槛。

四 · 常量只有在装配可重复时才有意义

标一次，用很多次 —— 前提是装回去还是那个位置

marker 到 TCP 的关系是一个标定出来的常量，标定一次以后长期使用。 但只要拆装一次这个常量就变一次，整套标定就失效。

实测对照很极端：靠人手扶定位，两次之间差 29.90 mm； 靠机械座定位，两次之间差 1.71 / 1.54 mm——相差 18 倍。 而单次之内两者都稳到 7–11 mm，肉眼完全看不出区别。

所以定位必须由机械特征保证（销孔 / 止口 / 台阶），螺钉加目视对齐不构成定位。

五 · 接口同构会让一整类误差自己相消 —— 这条决定了整体方案

采集器与执行器共用同一套基准 ⇒ 图纸误差在 record → replay 中抵消

前四条讲的是怎么把误差做小。这一条不同：它讲的是怎么让一类误差根本不必被测量， 因此它的价值高于前四条里的任何一条。

我们有一段量始终测不到：夹爪安装基准面到真实 TCP（那条 155 mm 的链）。 设真值为 G_real、图纸值为 G_model。 在标签侧，我们用 G_model 生成标签，于是标签相对真实演示动作偏了一个量 E。 在机器人侧，控制器同样用 G_model 计算它的 TCP，于是它把自己朝相反方向偏了同样的 E。

两者精确抵消，机器人的真实 TCP 落回真实演示动作上——而且 G_model 根本不出现在结果里， 也就是说图纸准不准都无所谓。 成立的唯一条件是：两台设备的夹爪相对各自安装基准的真实关系一样，即 G_real' = G_real。

但必须区分哪一段会抵消：会抵消的是「安装面 → TCP」这一段，因为标签侧与机器人侧都在用它。 而「rig → 安装面」那一段只出现在标签侧——机器人根本没有 rig 参与，没有东西跟它抵消， 所以那一段必须真的被测出来。这正是 M6 存在的理由。

这条推论会改变要求的优先级：件间一致性比绝对精度更重要。 对贵司而言这通常是好消息——同图纸、同工装、同一次装夹能保证的一致性， 往往比同等水平的绝对精度便宜得多。绝对公差仍然要（见 M7），但它服务的是另一件事： 用激光跟踪仪做外部认证时误差不抵消，那时才需要绝对值。

03

新设计需要同时支持的四件事

这一版夹爪不只是"装 marker 的载体"，它还要能被标定、被验证、被独立测量。四件事必须在同一个结构上成立。

用途它要求什么结构特征为什么现在没有它就卡住
A · 日常采集 低矮、刚性、分布在左 / 右 / 上三个方向的 marker 安装面，固定在夹爪的非运动刚体上 决定杠杆臂 L 与可见性——机制一与机制二
B · 平移标定 一个球窝特征，其球心在 CAD 中相对 TCP 的位置已知 marker→TCP 的平移量靠"球窝坐在固定钢球上、绕球心扫姿态"标出来。没有球窝就没有平移标定
C · 旋转标定 执行器上一套与采集器同构的可拆 marker rig；rig 安装基准两边同图、同公差 旋转常量在人手持状态下结构性不可测，必须借机器人的正运动学做 hand-eye。 执行器本来就在法兰上，是最省的一条路。见 §4-M6
D · 独立验收 靠近 TCP 的 SMR 磁性窝；FR3 侧另预留 6D 靶安装面 3 mm 这个指标目前无法被认证——没有独立参考。激光跟踪仪采购在推进，接口必须现在进设计

B 与 C 是两个独立的量，不能互相替代

球窝是一个 3 自由度球副：rig 绕球心任意旋转都不改变观测方程，旋转整个落在观测的零空间里。 这不是数据量问题，再多帧、再好的相机都测不到。我们算过用多球窝治具补救的方案： 要达到 0.22° 的目标，球窝间距需要 517 mm（乐观）到 1.5 m（现实）， 且三个球窝必须非共线、精度由最短边决定——一个三向都 ≥200 mm 的治具要夹在 45 mm 的指间还能绕球心大角度扫动，机械上不现实。

因此：平移走球窝（B），旋转走 FR3 hand-eye（C），两条路都要有对应的机械接口。

三种构型分别带什么

需要明确区分：marker rig 只在采集侧是必需的。下表说明每种构型的组成，避免把标定工装当成量产件、 或者把 rig 当成执行器的标配。

反过来说，这四组里任何一组在两种设备上"差不多但不一样"，抵消就失效， 而且失效的方式是安静的——数据看起来完全正常，只是机器人复现的动作系统性偏一点。 所以这四组基准必须在图纸上被显式声明为同一组，而不是各自标注后"看起来一样"。

04

硬性约束（必须满足）

以下每条都附了它的实测依据。若结构上确实无法满足，请提出替代方案与原因，不要静默放宽。

M1必须

所有 marker 属于同一个非运动刚体

marker 不必组成物理立方体，可以分布在不同的面上——我们的算法只要求所有可见角点属于同一刚体， 且在统一坐标系下有已标定的 3D 坐标。但这个刚体必须是不随夹爪开合运动的固定结构。

不得安装在随开合运动的手指、软壳、薄片或任何受力变形件上；marker 载体本身不得参与夹持、接触或受力路径。

并且：rig 的结构根部必须落在 BOX 本体一侧，也就是"卸下夹爪"这条分割线的上方。 原因见 M6——旋转标定要把夹爪卸下来，如果 rig 挂在夹爪上，夹爪一卸 rig 就跟着走了，整个标定方案不成立。 这一条与 M2 的短杠杆臂目标存在张力，处理办法见下方。

依据 见机制三。一旦松动，多相机一致性与重投影残差同时失明，错误标签不会被任何自动检查拦下， 而对应的处置是整批数据作废。2026-08-21 已经发生过一次。

M1 与 M2 会打架，请按下面的方式解

几何事实：TCP 位于夹爪基座安装面沿夹爪轴向 155 mm 处 （我方 URDF 中 link_lt_gripper_base → link_lt_gripper_tcp）。 所以如果 rig 的几何中心停在 BOX 的夹爪安装面附近，杠杆臂 L 至少是 155 mm —— 已经顶到 M2 的硬上限。

解法：rig 的结构根部固定在 BOX 一侧，支臂向下延伸到夹爪本体两侧， 把 marker 的几何中心拉到接触点附近。这样卸夹爪时 rig 原封不动留在 BOX 上，而 L 仍能做到 ≤100 mm。 我方 2026-08-18 的自制原型正是这个形态：五条支臂，marker 中心到接触点 103–153 mm， 合成杠杆臂 102.3 mm。

支臂向下延伸必然增加与工件、桌面的碰撞风险，这是已知要付的代价。 请在结构方案里把这个取舍显式做出来：支臂包络、离指尖的最小距离、 以及最坏姿态下支臂会不会先于手指碰到工件。

M2必须

杠杆臂 L ≤ 100 mm，硬上限 150 mm；marker 不得高于夹爪本体轮廓

L 定义为 marker rig 几何中心到夹爪 TCP（闭合状态）的距离。自制原型已经做到 102.3 mm 并验证有效， 说明这个量级是可实现的，不是理论值。

依据 旧高位 cube L = 241.5 mm，姿态误差折算到 TCP 为 p50 2.69 / p95 6.32 mm； 压到 102.3 mm 后为 1.20 / 2.59 mm。同时最差相机丢帧率 47.4% → 14.3%。 "立高"的代价是两项叠加，不只是碰撞风险。

M3必须

任一工作姿态下，每个相机方向至少 2 个非共面 marker 完整可见

布置面至少覆盖左 / 右 / 上三个方向，相邻安装面法线夹角建议 60–90°； 至少 3 个 marker 的法线线性无关，使单相机单帧也能约束全部 6 个自由度。

判据不是"多贴几个 marker"，而是对每一个相机位姿，都有 ≥2 个 marker 入射角 <60° 且四角完整在画面内。 这一条必须在 CAD 阶段用我方提供的相机外参直接验算，不能装完再看。

依据 三组独立实测都指向同一条：① 单个平面 marker 在 35–50° 入射角下 PnP 位姿二义性开始翻转，产生 >100 mm 的整帧错误，发生率 4.88%； ② 能同时看到 ≥2 个 marker 的四台相机，各自独立解出的杠杆臂最大只差 1.69 mm， 只看到 1 个 marker 的两台偏出 3–4.5 mm——而且它们自己的重投影残差反而最小（0.13 / 0.22 px），完全骗人； ③ 只被约 1.9 台相机看见的两个 marker，在几何重建里偏出 0.82 / 1.40 mm， 而可见性好的三个对上 CAD 到 0.05–0.28 mm。

M4必须

装配定位由机械特征保证，并支持反复拆装

需要销孔、止口、台阶或沉头定位面等真实定位基准，并带防装反特征（非对称孔位、定位销、缺角或键槽）。 螺钉 + 目视贴合不算定位。carrier 应能在不拆解夹爪核心机构的前提下装拆，紧固件需防松。

验收方式：同一 carrier 拆装重装 5 次，我方每次重跑一遍完整标定，看这 5 次结果的分散度。

依据 手扶定位 vs 机械座定位实测差 18×（29.90 mm vs 1.71/1.54 mm），而单次之内两者都稳、肉眼无法区分。 另：我方标定的不确定度将取这 5 次的实测分散度，而不是取标定算法自己的拟合残差—— 我们刚在"模型自评"上吃过一次亏（一份自评分数更好的相机标定恰恰是错的那份）。

M5必须

保留一个可标定的球窝基准，且其球心在 CAD 中精确给出

marker→TCP 的平移量靠定点 pivot 标定得到：rig 上的球窝坐在桌面固定钢球上，操作者绕球心扫掠姿态。 现用配合是球窝 R 12.68 mm 对 25 mm 钢球。请给出球窝的球径、配合间隙、球面加工方式与材料。

建议把 CAD 原点定在球窝球心。这样标定的正确答案就是 [0,0,0]， 我们不需要任何对齐就能直接读出整条链路的总误差——这是上一版原型能做出可信验收的关键。

依据 配合间隙不是无害项：球心落在窝里的哪一点由受力方向决定，而受力方向随 rig 姿态改变， 于是产生一个姿态相关的位移。这类位移正好落在标定方程的零空间里， 残差 / holdout / 逐段锚点三道检查全部失效。现有 0.18 mm 单边间隙估算最多贡献 0.44 mm 且不可见， 是当前残余 0.9 mm 误差的主要嫌疑之一。间隙越小越好。

M6必须 · 需确认

执行器带一套与采集器同构的 marker rig，hand-eye 在机器人上原位完成

这是本次需求中最重要也最需要贵司判断的一条。我们要测的是 A = rig → 夹爪安装基准面 这段安装角度，办法是让机器人正运动学提供 TCP 姿态、 多相机提供 rig 姿态，两者相比。

第一层 · 首选：在执行器上做一套与采集器同构的 marker rig。 执行器本来就装在 FR3 法兰上，所以这条路不需要任何转接件、不需要拆任何东西、也不需要动采集器， 标定在机器人上原位完成。这套 rig 建议做成可拆：标定与 QC 时装上，作业时可卸下。 前提是它与采集器共用同一组 rig 安装基准（见 M7）。

但这一层有一个必须写明的限制 机制五那个"自动抵消"只对「安装面 → TCP」成立，对本项这个 A 不成立—— A 只出现在标签侧，机器人那边没有 rig 参与，没有东西跟它抵消。 所以把执行器上测到的 A 用到采集器上，依赖 rig 安装基准的件间一致性： 在 102 mm 杠杆上，0.1° = 0.18 mm，0.2° = 0.36 mm， 0.5° = 0.89 mm。因此这条一致性要求是 ≤0.1°， 且它无法被 hand-eye 自身验证（只测了执行器那一台）。

第二层 · 建议同时做：在采集器本体上也留一个 FR3 法兰安装基准 （尾部一个基准平面 + 定位止口 + 法兰孔位）。它平时不用，但可以让每台采集器自己测一次 A， 于是上面那条一致性从"假设"变成"测量"，两者一比就直接得到件间差异的实测值。 如果代价不大，强烈建议做——这是目前唯一能验证同构是否真的成立的手段。

第三层 · 退路（仅在前两层都做不到时）： 把夹爪从本体上卸下，用夹爪原本那个安装面当转接面，做一块机加转接板—— 一侧复刻该安装面、另一侧是 FR3 法兰孔位。这块板占的正是夹爪自己的安装面， 与夹爪只能二选一，标定与录制之间必须换装，于是"夹爪重装重复性"变成一个新的、必须测量的误差项。 它必须机加、不能 3D 打印（本项要买的就是把 2.0° 压到 0.05°–0.1°，打印件守不住这个量级），1–2 件即可。 这个方案是从"改造现有硬件"的约束里来的——当时只能复用一个变换已知的面；对全新设计这个约束不存在。

需要贵司确认：执行器能否带一套与采集器同构的可拆 rig？rig 安装基准的件间一致性能做到多少？采集器本体上留一个法兰基准的代价有多大？

依据 现役标定包里记录的安装旋转不确定度 2.0° 是一个声明值，不是测量值 （出处写着"从 24 个轴对齐候选里按物理合理性挑了一个"，另一只夹爪是从第一只继承的，两条都不含任何直接观测）。 按现役杠杆臂 259.5 mm 折算即 9.1 mm——3 mm 预算的三倍， 是目前误差账本上最大的单项。而 2.0° → 0.05° 是 20 倍以上的改善，且误差从此有出处。

这个方案剩下的那一段：安装面 → TCP 仍然是 CAD，不是测量

必须如实写清楚链路的两半： rig →〔hand-eye 实测〕→ 夹爪安装基准面 →〔URDF / CAD，未测〕→ 真实 TCP。 hand-eye 精确给出前半段，后半段仍然来自图纸——夹爪装着标也一样， 因为 hand-eye 观测的是法兰与 rig 的相对运动，夹爪在不在场都不会让"安装面到 TCP"变成被观测量。

所以这个方案的实际收益是把未测量的对象换小： 从"整个 rig→TCP 旋转（2.0°，出处是从 24 个候选里挑的一个，无人对它负责）"， 换成"夹爪自身几何相对它自己的安装基准"——后者由贵司加工控制，可以给出公差。 在 155 mm 杠杆上折算：0.1° = 0.27 mm， 0.2° = 0.54 mm，0.5° = 1.35 mm， 对照现值 2.0° 在 259.5 mm 上的 9.1 mm。

我方会用三件事把这一段收掉：① 向贵司要 TCP 相对安装基准面的公差（见 M7 与第 9 节）； ② 用 pivot 做交叉检验——pivot 是用真夹爪、真指腹夹住球窝治具测出来的， 它给出的 rig→接触中心平移独立于 URDF，可以直接检验图纸对不对； ③ 把"夹爪拆装重复性"补进采集协议（见第 6 节）——既然流程里要卸夹爪，这一项就不能不测。

M7必须

rig、夹爪、法兰三组基准做在同一零件上，并给出公差与件间一致性

这是上面那段残差的结构性解法，比事后标定便宜得多： 让 marker rig 的定位特征、夹爪安装基准面与 FR3 法兰基准面成为同一个刚性零件上的三组特征，尽量一次装夹加工完成。 这样"rig 在哪"与"夹爪在哪"之间的关系是一条有公差的机加尺寸， 而不是若干个装配接口叠出来的未知量。

请随件给出：

  • 件间一致性：同批次不同单元之间，夹爪 TCP 相对安装基准面的差异—— 按机制五，这是比绝对精度更重要的一个数，因为 record → replay 抵消的成立条件是 采集器与执行器"一样"，不是"准"；
  • 夹爪 TCP（闭合状态）相对夹爪安装基准面的位置度与角度公差（绝对值，用于外部 GT 认证）；
  • 该基准面的平面度与孔位度；
  • 夹爪重复拆装的重复性（因为标定流程里要卸下再装回）；
  • 夹爪安装接口必须带定位销，不得只靠螺钉过孔定位——过孔间隙会让每次重装落在不同位置， 而这个位移经 155 mm 杠杆直接进 TCP；
  • rig 定位特征与该基准面之间的位置/角度公差，以及是否同一次装夹加工。

依据 这四个数会直接成为误差预算里"安装面 → TCP"那一段的数值。 目前这一段在我方账本上是空的，只能按最坏情况留余量。 给出一个 0.2° 的实测公差，比给出一句"符合图纸"有用得多—— 前者能让我们把这一项关掉，后者只能让我们继续按 1° 计。 而件间一致性那一条更关键：按机制五，只要采集器与执行器的这段几何一致， 图纸误差在 record → replay 里自动抵消；一致性做得好，可以放宽绝对精度要求。

关于"夹层式常驻转接板"这个替代方案

转接板与夹爪抢的是同一个安装面，所以标定与录制之间必须换装。 一个自然的替代想法是把转接板做成常驻夹层：BOX 面 → 转接板（永久安装）→ 夹爪装在板的外侧， 法兰孔位另做在板上，录制时那个面空着不用。我方评估过，不作为默认方案，但贵司可以提出—— 提出时请一并回答下面三笔代价。

它买到的：夹爪永不拆卸，本页"夹爪拆装重复性"一项消失；pivot 测到的真实接触点常量长期有效； 标定构型与录制构型完全一致。

它要付的：① 杠杆臂增加一个板厚，与 M2 直接冲突，而 M2 是目前唯一被实测证明有效的精度杠杆； ② 同轴的法兰面被夹爪占了，只能侧面出耳或另开孔圈，这个结构在录制时一直挂着——增加质量与包络， 并可能遮挡 marker（2026-08-21 的中间版本正是这样翻的车）； ③ URDF 多一段，板厚成为新的 CAD 输入。

我方倾向：维持换装方案 + 定位销。一对定位销就能买到夹层方案想买的重装重复性， 而且不用付上面三笔。另外"夹爪拆装重复性"在换装方案下是可测的——做 5 次就有数进预算； 消掉一个本来就能测的误差，价值没有看上去那么大。

最后说明：两种方案对"安装面 → TCP 是 CAD"这段残差没有区别。 hand-eye 无论哪种接法都不观测 TCP，夹爪在不在场都一样；夹层方案消掉的只是"夹爪重装"那一半。

M8必须

marker 安装面为平整刚性基材，贴附厚度需给出

marker 下方必须是平整刚性基材，避免纸张翘边、胶层不均、薄壁变形。 表面哑光低反光，marker 周边避免高亮金属反光边。请给出推荐材料、表面处理与贴附工艺， 并明确 CAD 中标注的是贴标面还是 marker 成像平面，以及两者之间的厚度。

依据 这不是形式要求：我们的视觉重建能测出一张贴纸的厚度。 实测贴纸厚 0.75 mm，扫描拟合给出 0.82 mm，两者差 0.07 mm。 也就是说亚毫米级的贴附偏差会进入我们的几何模型；说清楚比做到更重要。

M9必须

marker 的 ID、字典、尺寸、所在面、朝向唯一可追溯

每台设备使用独立的 layout 记录（按设备编号索引，不按左右手），避免任何镜像假设。 所有 marker 请使用同一尺寸的贴纸。交付 marker layout 表格与装配照片。

依据 同尺寸贴纸是一把免费的绝对标尺：我们从图像里量出的每个 marker 边长偏差， 就是该 marker 局部重建误差的绝对读数（实测 ±0.5%，两次采集复现到 0.02–0.17 mm，属系统项）。 尺寸不一致就损失了这个交叉校验。

M10必须

TCP 固定在夹爪本体坐标系里，不随开度移动

新版本请把 TCP 定义成夹爪本体上的一个固定点——参照 Franka Hand / Pika gripper 的做法： TCP 相对安装基准面的位置由结构决定，开合手指不改变它。 开度 d 仍然作为一个独立的自由度上报，但它不得出现在 TCP 的位姿里。 若结构上必须让接触点随开合移动，请把两者分成两个量： 一个固定的 tcp（我们用它做标签与标定）、一个随 d 变化的 contact_point（我们只在分析里用）。

依据 现役夹爪的 TCP 是随开度后退的，用的是贵司给的解析式 z = R − √(R² − A·d − d²/4)（R = 49.8361、A = 4.0456 mm，d 为真实指尖距）。 这条曲线不是小量：闭合到 70 mm 开度，TCP 沿手指轴后退 18.6 mm；到公式定义域上限 91.9 mm 时后退 49.8 mm。 它造成三个我们无法在软件里消化的后果—— ① 它把「marker → TCP 常量」变成了不是常量。整条测量链的前提是 marker rig 与 TCP 同属一个刚体（机制三、M1）， TCP 一旦随 d 移动，这段变换就标不出来，误差预算里最大的一项（9.1 mm 的安装旋转）也就没有可收敛的对象。 ② 它把开度传感器塞进了标签的误差链。灵敏度 dz/dd 随开度急剧上升：35 mm 处 0.24、70 mm 处 0.63、85 mm 处 1.27、89 mm 处已超过 2.0 mm/mm。 而开度通道本身只准到约 ±1 mm（硅胶指腹每侧压缩约 0.5 mm，这是物理下限），且在 89.8 mm 处实测系统性多报 +3.3 mm—— 若不校正，仅这一项在高开度端就折算成 6 mm 以上的标签误差，而我们的总目标是 3 mm。 我方目前靠一张实测折点表把它修回来，但「必须维护一张折点表才能得到正确标签」本身就是这个 TCP 定义的代价—— 它把一个机械常量换成了一条需要长期标定、且会随指腹磨损漂移的曲线。 ③ 它让机制五的误差相消失效。若执行器侧用的是 TCP 固定的夹爪，而采集器侧的 TCP 随 d 移动， 两侧的差不是一个静态变换，而是一条随开度变化的曲线，无法用任何常量补偿； 训练数据里还会出现一种物理上不存在的耦合：「张开手」被记成「末端后退了 18 mm」。 补充一条工程上的信号：该公式在 91.9089 mm 处根号归零、导数发散，而开度流的原始读数在真实开度约 89 mm 时就会越过这个上限—— 一个在正常工作行程内就会出现奇点的 TCP 定义，本身说明它不适合当标签口径。

交付物

CAD 不只是参考件——它会作为我们几何重建的先验参与计算，所以它必须描述真实设计意图。

D1交付

CAD（STEP）+ URDF + mesh

URDF 需包含 carrier、每个 marker 安装面、夹爪接口、TCP 与球窝的坐标系命名及相对位姿； 若引用外部几何请同步提供 STL / DAE / OBJ。

依据 我们的 layout 求解把 CAD 当先验而不是硬约束（面心 σ ≈ 1 mm、法线 σ ≈ 1°）， 实测这是三种方案里最好的一种：完全冻结 CAD 会把约 1 mm 的装配公差原样引进来（|误差| 1.35 / 1.29 mm）， 完全放开则让弱观测的 marker 有厘米级自由度，而先验方案两头都占（0.90 / 1.03 mm）。 所以 CAD 有公差是可以接受的，CAD 与实物系统性不符则不可以。

08

设计禁区

以下方案原则上不接受。每一条都对应上文的某个机制，不是偏好问题。

  • marker 安装在随开合运动的手指上（机制三）
  • marker carrier 参与夹持或处于受力路径上（机制三）
  • 仅靠胶带、薄纸或 3D 打印薄壁件作为最终定位基准（机制三 / 四）
  • 高位立柱式结构，marker 高出夹爪本体轮廓（机制一 / 二）
  • marker 面可手动晃动，或长期使用后会弯曲（机制三）
  • 只靠螺钉 + 目视对齐定位，无机械定位特征（机制四）
  • 无法追溯 marker 的 ID、朝向与尺寸（M9）
  • 为缩短杠杆臂而牺牲 marker 可见性（2026-08-21 中间版本的教训）
  • TCP 随开度沿手指轴移动，或 TCP 与接触中心合成为同一个随开度变化的量（M10）

建议的推进流程

① 贵司先回复第 1–4 项 —— 这三项不依赖完整结构方案，却决定整体路线：第 1–2 项决定标定怎么做、以及那条一致性能不能被验证，第 3 项决定一整类误差是「必须测量」还是「自动抵消」，第 4 项是我方误差预算里唯一一段还空着的数。 ② 提交初版结构方案与材料方案，双方评审包络、可见性、安装与维护方式。 ③ 若能先给出 marker 安装面的 CAD，我方可立即用现有相机外参对候选布局排序， 把可见性验算的结果反馈成具体的面位调整建议——这一步在打样之前做，成本最低。 ④ 提交 CAD / URDF / layout 表与报价。⑤ 加工 2–3 套样件。⑥ 我方按第 6 节完成六组测试。⑦ 冻结或迭代。
